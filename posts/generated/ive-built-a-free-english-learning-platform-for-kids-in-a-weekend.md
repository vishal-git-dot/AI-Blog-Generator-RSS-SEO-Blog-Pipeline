# I've built a free English learning platform for kids in a weekend

## Overview

I've been a software developer for a long time — everything from small WordPress projects to complex service-oriented architectures. I've never been more scared and excited at the same time. Working with AI tools on a complex code base became possible in 2026, and I wanted to see what Fable 5.1 can do on a new project. I started with a design doc: what the website does, what it's for, etc. I added the tech stack, learning a few things along the way — I'd never used Vercel before. Results are in: The design: nailed it. The logo needed some manual tweaking, and I did a bit of rearranging of existing elements, but otherwise excellent work by Fable. Backend: as a true "vibe coder", I didn't even check the code, but it's working and I have e2e Playwright tests :) I got to try Jev for classification, and it worked great. Apart from the tech stack, I don't recall any major technical input that was required from me. The model decided on the file structure, the npm packages and how to get voice MP3 files. I was mostly working as a QA/PM person. Surely, to scale this up, more technical input would be required. But for an MVP, the speed at which you can validate your idea is mind-blowing!
