# Fetching Details on Washington Entity Records Multiplies Turnstile Runs

## Overview

Washington State's Corporations & Charities Filing System (CCFS at ccfs.sos.wa.gov ) is the single source of truth for business entity registration in the state. Whether you are validating vendors for anti-fraud compliance, tracking corporate officer turnover, or monitoring newly registered LLCs, querying this database programmatically presents an immediate architectural hurdle: the site is a JavaScript single-page application enforcing Cloudflare Turnstile challenges across both search submissions and individual entity record pages. Automating data collection from CCFS requires handling these challenge-response cycles without stalling your ingestion pipelines or incurring unnecessary execution overhead. The Trade-off Between Summary Search and Full Detail Enrichment When querying CCFS records via the Washington SOS Business Search Scraper , the search operates across three distinct modes: byBusinessName , byUBINumber , and advancedSearch . A critical technical decision in pipeline design is whether to set fetchDetails to true or false . { "mode" : "byBusinessName" , "businessName" : "Microsoft" , "nameMatchType" : "ExactMatch" , "fetchDetails" : false , "maxItems" : 10 } When fetchDetails is false , the scraper extracts data directly from the registry's initial search results table. This summary query handles the Turnstile verification once on search submission and yields core metadata: businessName and dbaBusinessName ubiNumber (Unified Business Identifier) businessType and businessTypeId businessStatus (e.g., ACTIVE , DELINQUENT , TERMINATED ) principalOfficeStreetAddress and principalOfficeMailingAddress registeredAgentName Setting fetchDetails: true instructs the actor to navigate to the individual entity page for every record returned in the search. Because the CCFS system re-verifies Cloudflare Turnstile challenges on each detail page, deep queries take significantly more execution time and run a higher risk of challenge timeouts. However, detail enrichment extracts fields not present in the search grid: Officer records ( governors[] containing { name, title } ) Full registered agent address objects ( registeredAgentStreetAddress , registeredAgentMailingAddress ) formationDate , expirationDate , and inactiveDate jurisdiction and NAICS natureOfBusiness Specialized nonprofit attributes ( nonprofitEIN , isCharitableNonprofit , grossRevenueOver500k ) If your downstream data warehouse only requires validation of legal standing or entity status checking, keep fetchDetails: false and set maxItems higher. Restrict fetchDetails: true to targeted lookups using small batches or precise lookups via ubiNumber .
