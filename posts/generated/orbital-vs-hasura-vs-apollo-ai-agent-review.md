# Orbital vs Hasura vs Apollo: AI Agent Review

## Overview

Orbital, Hasura, and Apollo all do similar things. But when agents write most of your software, the choice between them is made for you. Here’s which one your agent prefers, and why. Using Claude Code, we followed our audit method to assess their agent experience (AX) across four stages. The four stages of an AX audit The audit follows the funnel a developer goes through with their agent: Awareness → Discoverability → Reputation → Integration We started with what the model knew without tools, then tested online discovery and recommendations with web search and fetch, and finally attempted a working integration with the full toolset. Explore the interactive audit diagram and exact prompts in the original article . Awareness: Does the model already know about the product, without tools? Discoverability: Does it find the product when it searches online? Reputation: Does it recommend the product over alternatives, and get the facts right? Integration: Can it build and verify a small working integration? Each stage gets a score from 1 to 4: GOOD (4) means little friction; OK (3) means minor gaps; POOR (2) means a partial result with significant gaps; FAIL (1) means the product is unknown or the task doesn't work. How we tested All testing used Claude Opus 5.5 ( claude-opus-5-5 ) in Claude Code 2.1.287, on 13–14 October 2026. Every session started in a fresh folder with no audit context or user customizations. Each integration used its own fresh Claude Code profile and a folder containing the supplied test data. Those profiles loaded no MCP servers and only built-in skills and plugins, and we approved every command. Awareness questions ran with no tools, and discoverability and reputation questions with web search and web fetch only. We ran each prompt once, so treat these results as one developer's experience rather than a benchmark. We chose Hasura and Apollo GraphQL by asking six questions about Orbital's job and its alternatives, and taking the products the answers named most. Both appeared in all six answers. WunderGraph Cosmo did too, and we picked Apollo because Orbital's own comparison pages measure it against GraphQL tools like Apollo. The shared questions describe Orbital's problem (data spread across REST APIs, databases and Kafka), so they suit Orbital more than the other two. What are Orbital, Hasura and Apollo GraphQL? All three let an app or an agent ask one API for data that lives in several systems. Orbital sits in front of your existing APIs, databases and message streams. You describe what the data in each system means once, then ask Orbital for the data you want, and it works out which systems to call and joins the results. Our Orbital quickstart covers how it works in more detail. Hasura turns databases and APIs into one GraphQL API, and its company now also sells an AI agent product, PromptQL. Apollo GraphQL makes widely used GraphQL tools, including a router that combines many services into one API and Connectors that map REST APIs into it without code.
