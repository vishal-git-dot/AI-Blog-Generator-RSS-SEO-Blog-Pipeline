A logistics report has three separate identities: the business report, its exact bytes, and a delivery attempt. Keep them separate. A corrected attachment can belong to the same shipment review, but it must have a new content digest. An intentional resend of unchanged bytes retains the report and digest while receiving a fresh attempt ID. The same principle applies to an OTP resend: a new attempt may represent a deliberate user action, while a repeated command with the same idempotency key is just the same action arriving twice.
