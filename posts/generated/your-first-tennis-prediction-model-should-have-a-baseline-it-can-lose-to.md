## Overview

The first useful result from a tennis prediction project is not necessarily a clever forecast. It may be discovering that your learned model is worse than the rating you already had. This tutorial builds a very small logistic model using one input: the difference between two players' pre-match overall Elo. It compares that fitted model with a 50/50 prediction and the ordinary Elo probability formula. There is no language model guessing the winner from a player's name.
