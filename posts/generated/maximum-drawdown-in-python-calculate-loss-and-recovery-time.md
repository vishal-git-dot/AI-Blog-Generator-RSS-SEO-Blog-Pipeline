# Maximum Drawdown in Python: Calculate Loss and Recovery Time

## Overview

A backtest finishes 26% ahead. In the middle, its value falls from 120 to 90. The final return looks comfortable; the path includes a 25% loss from a previous high. Maximum drawdown is the largest percentage decline from an earlier peak to a later trough within the data you measure. In Python, a running maximum gets you most of the way there. A useful report also needs the peak date, trough date and recovery status. This guide calculates maximum drawdown with pandas, handles an unrecovered loss, and plots an underwater chart. You can run the worked example without an API key, then use the same calculation with a historical market data CSV. Maximum drawdown formula For each observation, keep the highest value seen so far: running peak[t] = maximum value from the start through t drawdown[t] = value[t] / running peak[t] - 1 maximum drawdown = -minimum(drawdown) The drawdown series is zero at a running high and negative below it. We report maximum drawdown as a positive loss magnitude: a drawdown of -0.25 becomes a maximum drawdown of 25% . Other software may return a negative number, so check the convention before combining reports. Order matters. Comparing the highest and lowest values anywhere in a file can put the low before the high. A drawdown requires the peak to happen first. A running maximum preserves that order.
