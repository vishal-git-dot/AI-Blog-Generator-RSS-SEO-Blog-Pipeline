# 768 PixVerse effect templates, one API, and a no-code playground

## Overview

On 19 November 2026, ModelFold is serving 768 official PixVerse video-effect templates on the PixVerse V6 image-to-video model. That count is from the live catalogue the Playground itself uses. New templates are pulled in on a six-hour timer, so the number can grow. You can browse every preview, pick a template, upload a photo, and get a video. The same template_id works over the API, which is the useful part if you want more than one clip. No-code path Open the V6 image-to-video page, stay on Playground, and click Preview all templates . The dialog lists the current count, search, stills, and looping preview video. Hover or tap a card to play it. Then: Click Use template . Upload the number of images the card asks for, in that order. Leave duration alone.
