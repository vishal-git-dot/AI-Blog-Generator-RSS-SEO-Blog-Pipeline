Les premiers concepts, dans l'ordre Pour apprendre Python, l'ordre compte plus que la vitesse : chaque notion s'appuie sur la précédente. Variables, types et affichage Une variable est un nom posé sur une valeur. Python déduit le type tout seul, et les f-strings servent à insérer une valeur dans un texte. prenom = " Inès " age = 24 taille = 1.68 inscrite = True print ( type ( age )) # <class 'int'> print ( f " { prenom } a { age } ans " ) # Inès a 24 ans 2. Conditions Une condition exécute un bloc selon un test. L'indentation délimite les blocs (par convention, quatre espaces) : c'est la première règle de syntaxe à respecter. note = 14 if note >= 16 : print ( " Très bien " ) elif note >= 10 : print ( " Admis " ) # affiché, car 14 >= 10 else : print ( " Ajourné " ) 3. Boucles for parcourt une séquence, while répète tant qu'une condition est vraie. range(3) produit 0, 1 et 2. for i in range ( 3 ): print ( i ) # 0, puis 1, puis 2 compteur = 3 while compteur > 0 : print ( compteur ) # 3, puis 2, puis 1 compteur -= 1 4. Listes et dictionnaires La liste range des valeurs dans l'ordre, le dictionnaire associe des clés à des valeurs. Ce sont les deux structures que vous utiliserez tous les jours. langages = [ " Python " , " SQL " , " Bash " ] langages . append ( " JavaScript " ) print ( langages [ 0 ]) # Python print ( len ( langages )) # 4 profil = { " nom " : " Inès " , " niveau " : " débutant " } profil [ " objectif " ] = " data " for cle , valeur in profil . items (): print ( cle , " = " , valeur ) # nom = Inès # niveau = débutant # objectif = data 5. Fonctions Une fonction regroupe des instructions réutilisables. Les annotations de type ( float ) sont facultatives mais rendent le code plus lisible. def prix_ttc ( prix_ht : float , taux : float = 0.20 ) -> float : """ Renvoie le prix TTC arrondi au centime. """ return round ( prix_ht * ( 1 + taux ), 2 ) print ( prix_ttc ( 100 )) # 120.0 print ( prix_ttc ( 100 , 0.055 )) # 105.5 Les nombres à virgule ( float ) sont approchés en binaire : pour de vrais montants en euros, la bibliothèque standard propose le module decimal , qui calcule en base 10. 6. Erreurs et exceptions Lisez les messages d'erreur en entier : la dernière ligne nomme l'erreur. try et except permettent de gérer une saisie invalide sans planter. saisie = input ( " Votre âge : " ) try : age = int ( saisie ) except ValueError : print ( " Merci de saisir un nombre entier. " ) else : print ( f " Dans 10 ans, vous aurez { age + 10 } ans. " ) 7. Modules et bibliothèques Un module se charge avec import . Commencez par la bibliothèque standard ( random , pathlib , csv , json ) avant d'installer des paquets avec pip . Les classes viennent ensuite, au chapitre 9 du tutoriel officiel. Vos premiers projets Un projet par semaine vaut mieux qu'un cours de plus. Commencez par des programmes en console, puis ajoutez une bibliothèque externe. Cinq idées classées par difficulté : Le nombre mystère : conditions, boucles, module random . Un générateur de mots de passe : chaînes et module secrets . Un carnet de dépenses : dictionnaires, fichiers CSV, exceptions. Un trieur de fichiers : modules pathlib et shutil , pour ranger un dossier de téléchargements par extension. Le premier tient en une vingtaine de lignes. while True répète la boucle sans fin, et break en sort dès que le nombre est trouvé ; le bloc try reprend la gestion des erreurs vue plus haut. import random secret = random . randint ( 1 , 100 ) essais = 0 while True : try : proposition = int ( input ( " Votre nombre entre 1 et 100 : " )) except ValueError : print ( " Merci de saisir un nombre entier. " ) continue essais += 1 if proposition < secret : print ( " C ' est plus. " ) elif proposition > secret : print ( " C ' est moins. " ) else : print ( f " Trouvé en { essais } essai { ' s ' if essais > 1 else '' } . " ) break Pour le générateur de mots de passe, n'utilisez pas random : la documentation demande de préférer le module secrets , car random est conçu pour la simulation, pas pour la sécurité ( module secrets ).
