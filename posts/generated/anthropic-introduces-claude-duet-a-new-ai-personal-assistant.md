# Anthropic introduces Claude Duet, a new AI personal assistant

## Overview

Anthropic introduced Claude Duet as a research preview, a personal AI agent running on a dedicated virtual machine with standalone mobile apps. It integrates with connected applications to automate tasks and generate daily briefings, featuring a new classifier designed to prevent sensitive data leaks. The new tool can create a daily to-do list from connected apps, schedule meetings, and even create websites and financial forecasts. Duet operates behind the scenes in its own isolated environment and has separate apps for Android and iOS phones. To conserve resources, the assistant checks connected accounts every few hours. Security and data protection The company has implemented new security mechanisms and guidelines to prevent sensitive information from leaking. According to Anthropic, the assistant never directly sees passwords or digital login keys.
