# From Local Archives to Cloud: Seamlessly Moving MSG Files to AOL Mail Using WholeClear MSG to IMAP Converter

Overview An 86-person legal consulting firm had 12,480 Outlook MSG files of archived client correspondence collected over a seven-year period. The management decided to transfer the entire archived emails to AOL Mail, so now the employees can access the old conversations from anywhere without using Outlook. The archived MSG files were arranged in 37 department-specific folders like Client Agreements, Legal Notices, Financial Records, HR Documents, and Internal Communication. It was important to keep the current folder structure as people often searched emails based on department folders. The IT team first tried a number of manual methods but found they either took too long or completely destroyed the original folder organization. Ultimately, they implemented a dedicated migration solution that successfully completed the project while maintaining every folder in its exact original state. Employees needed uninterrupted access during migration. The migration needed to be done in a single weekend. Avoiding server-side rate limits and managing pre-corrupted source files. Significance Outlook message files are proprietary and trapped locally. MSG to IMAP conversion moves Outlook message files to a universal cloud archive.
