# I built a Windows tool to inspect Python dependencies without running the project

## Overview

Ever inherited a Python project and wondered which third-party packages it actually uses? That's the problem behind ImportSmith 1.0 , a Windows desktop utility from RooTech. ImportSmith performs static inspection of Python source code. It identifies imports, helps map them to likely distributions, compares observed imports with declared dependencies, and exports reports for review. Crucially, it doesn't execute the project being inspected . Static analysis has limits: dynamic imports, optional dependencies, and ambiguous module names need human review. The results are a starting point for dependency auditing, not an instruction to blindly install or remove packages.
