# One API for Greenhouse, Lever, Ashby, Workable, SmartRecruiters and Recruitee jobs (with a daily new-jobs feed)

## Overview

Many products need fresh job postings: job boards and aggregators, recruiting agencies watching target accounts, sales teams using hiring as a buying signal, market researchers counting roles by function. The good news is that most tech companies publish their jobs through an applicant tracking system (ATS) with a public, documented job-board API . Greenhouse, Lever, Ashby, Workable, SmartRecruiters and Recruitee all have one. The bad news is that there are six of them, with six different JSON shapes, six ways of writing a location, salary fields in some and not others, and none of them tells you which ATS stripe.com uses. This tutorial uses the Greenhouse, Lever & Ashby Jobs API – All ATS Job Boards , an Apify Actor our team at Ostrata built to put all six behind one input and one output schema. It also has an only-new mode : schedule it daily and each run returns only the postings it hasn't seen before.
