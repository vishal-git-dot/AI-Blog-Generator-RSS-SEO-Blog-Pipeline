# How to bulk-verify EU VAT numbers and companies (VIES, LEI, SIREN) with one API call

## Overview

If you onboard B2B customers, suppliers or marketplace sellers in Europe, sooner or later someone asks: is this company real, active, and is its VAT number valid? Answering that by hand means opening several tabs. You check the VAT number in the European Commission's VIES service, look the company up in the national register (Sirene/RNE in France, Brønnøysund in Norway, PRH in Finland, ARES in Czechia), search GLEIF for an LEI, and for French companies look through BODACC for insolvency notices. That's fine for one company. For a CSV of 2,000 it isn't. This tutorial shows how to do the whole check in bulk with the EU Company Verification (KYB): VIES VAT, LEI, SIREN Actor on Apify, which our team at Ostrata built and maintains. You send a list of strings and get back one record per company with a verdict and the machine-readable reasons behind it. At the end there's a second Actor for when you only have a website , not a company number. What you can put in The input is a list. Each line can be: a company name ( Doctolib ), searched in the default country's register a French SIREN or SIRET ( 552 120 222 ), a Norwegian org number, a Finnish Y-tunnus or a Czech IČO an EU VAT number ( FR40303265045 , DE811569869 , IE6388047V ) an LEI ( 969500BPSLCSC039UV67 ) any of the above with a country prefix to force the country: NO: Equinor , CZ: Alza Identifiers are detected automatically. The other input fields are optional: Field Default What it does defaultCountry FR Register used for bare names: FR , NO , FI , CZ , or ANY (GLEIF LEI index) checkVat true Live VIES check (the VAT number is derived from the SIREN for France) checkLei true GLEIF LEI lookup and status checkInsolvency true BODACC collective proceedings (last 3 years) for France, registry flags elsewhere maxCandidatesPerQuery 1 How many matches to return per name search minNameScore "0.5" Drop weaker name matches; below 0.85 the verdict becomes review excludeSoleProprietors true Name searches return legal entities only includeRaw false Attach the raw registry payload concurrency 3 Parallel queries (each upstream API is also rate-limited per host) Step 1: Run it from the Console Open apify.com/ostrata/eu-company-check and click Try for free . Honest limits Full register adapters exist for France, Norway, Finland and Czechia . Elsewhere, VAT numbers are checked in VIES and names are searched in GLEIF, which only covers companies that hold an LEI. Germany, Spain and some other member states never return a name or address through VIES, so you get vatValid but legalName: null . VIES nodes go down or throttle. The Actor retries, then returns vatValid: null with a warning instead of a false "invalid". Website to Company does not render JavaScript, so pages built only client-side are not read. Neither Actor returns people's data: no directors, shareholders, emails or phone numbers. Sole proprietors are excluded by default. Results reflect the sources at query time.
