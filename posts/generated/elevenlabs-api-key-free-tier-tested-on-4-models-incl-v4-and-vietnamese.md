# ElevenLabs API key: free tier tested on 4 models, incl. v4 and Vietnamese

## Overview

An ElevenLabs API key works on the free plan, and it is enough to try every current text-to-speech model, including Eleven v4. We created one with a 2,000-credit cap and ran the same sentence through four models in English and Vietnamese, then hit the free plan's walls on purpose to see the exact errors. Below: how the key behaves, what each call cost in credits, how fast it was, and what the free tier blocks. Measured on 24 Oct 2026 with one key on an ElevenLabs Free account, from a Python script on a Windows 11 PC (WSL, Ubuntu 24.04) in Vietnam. Prices are from ElevenLabs' pricing pages, read the same day. Key results The free key ran all four models we tried : Flash v2.5, Multilingual v2, v3 and the new v4. Each call returned a 128 kbps MP3 of about 8–9 seconds for a 140-character sentence. Flash cost half. A 140-character sentence cost 70 credits on Flash v2.5 and 140 on the other three. The API says so in a character-cost response header on every call. The usage counter lags. Right after eight calls, /v1/user/subscription still showed 0 credits used; a few minutes later it showed 1,050, exactly the sum of the headers. Pick the model by language. Played back through ElevenLabs' own speech-to-text, Vietnamese from Flash v2.5, v3 and v4 came back word for word; Multilingual v2, which does not list Vietnamese, came back garbled (61% word error rate). Streaming is fast. Flash v2.5 over the streaming endpoint sent its first audio bytes in 0.19 s and finished in 0.40 s. The free tier blocks three things we tried : 192 kbps MP3 (Creator and up), 44.1 kHz PCM (Pro and up) and voices from the community library (Creator and up). The 21 default voices work. Setup Account: ElevenLabs Free, 10,000 credits a month, no payment method. Key: created on 24 Oct 2026 in the ElevenLabs web app under Developers → API Keys, with a 2,000-credit limit and no expiry. It sits in an .env file on the server that runs the script, never in a browser. Client: Python 3.13 with httpx , calling https://api.elevenlabs.io directly with the xi-api-key header (no SDK). Voice: "Bella", the first of the 21 default voices the key could list. Text: one sentence of 140 characters in English and one of 140 characters in Vietnamese, the same meaning in both. Checks: credits from the character-cost header and from /v1/user/subscription ; timing from the start of the request to the last byte; Vietnamese accuracy by sending each file to /v1/speech-to-text ( scribe_v1 ) and comparing the transcript with the original sentence. Audio length is estimated from file size at 128 kbps. How to get an ElevenLabs API key Sign in to ElevenLabs (a free account is enough). Open Developers → API Keys and create a key. Give it a name per app, and set the limits ElevenLabs offers: which endpoints the key can call, a credit quota, and an IP allowlist. We set a 2,000-credit quota so a bug in the script could not drain the month's 10,000 credits. Store it as an environment variable ( ELEVENLABS_API_KEY ) on your server. Send it in an xi-api-key header on every request. A first test call is GET /v1/models , which lists the models your key can use. ElevenLabs' docs say plainly that the key is a secret and should not go into client-side code such as browsers or apps. For calls that must come from the client, the docs point to single-use tokens instead. What worked One environment variable and a header: the first request worked without an SDK. The character-cost header gave an exact cost per call immediately, which the subscription endpoint did not. The per-key credit cap is a cheap safety net. Ours capped the test at 2,000 of the month's 10,000 credits. Every limit we hit came back with a readable message that names the plan you need. What didn't work The usage counter was not real-time. If you meter your own users from /v1/user/subscription , you will undercount; read the response header instead. Multilingual v2 accepted Vietnamese text and charged full price for unusable audio. One sentence per model is enough to spot a broken language, not to rank voice quality. We did not run long texts, many voices or a listening test. Our verdict If you want to try ElevenLabs from code, a free API key is enough: it runs the newest model, v4, and the cheap Flash model, returns usable 128 kbps audio, and its limits are clear. Put a credit cap on the key, keep it server-side, and log the character-cost header rather than trusting the usage counter. For a language other than English, check that it is in the model's list first: Flash v2.5 was the cheapest and fastest model that read our Vietnamese correctly.
