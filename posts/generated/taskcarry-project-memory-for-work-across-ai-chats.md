# TaskCarry: project memory for work across AI chats

## Overview

I’m building TaskCarry because using more AI chats shouldn’t mean doing more handoffs yourself. One chat updates a draft. A teammate reviews another version. Days later, you’re digging through conversations to work out what was actually approved. TaskCarry is an open-source project memory and collaboration toolkit. It connects decisions, work and next steps across AI chats and teammates into one lasting project record. Which version did we actually agree on? Engineering finishes a change. Someone else reviews it. A third person continues the project later. The useful handoff is more than “done”: the work, the review, and the version the team accepted need to stay connected. TaskCarry gives collaborators a saved project record to return to instead of piecing together scattered chats. We solved this before. Where did that experience go? A useful method shouldn’t disappear when you switch chats or collaborators. Keep the earlier solution with the project so the next collaborator can find what worked and decide whether it fits the current task. Bring AI together. Keep projects moving.
