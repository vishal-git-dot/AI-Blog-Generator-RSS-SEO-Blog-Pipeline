# How to Verify Uber Without Using Your Personal Phone Number

## Overview

Uber requires a phone number at signup and uses it as the primary way to confirm a trip request. That's a hassle if you're testing a ride-hailing integration, setting up a regional test account, or would rather not tie a rideshare account to your personal number. Steps Rent a number for Uber — an instant rental is enough for the signup verification. On Uber's phone-verification step, enter the rented number with its country code. Uber sends a verification code by SMS within seconds on a working number. Enter the code from your rental's status page to finish verifying. Instant or monthly? An instant rental is enough for the initial verification. A monthly rental only makes sense if you plan to keep using that same number to log into the account over time, since Uber may re-send a code on a new device.
