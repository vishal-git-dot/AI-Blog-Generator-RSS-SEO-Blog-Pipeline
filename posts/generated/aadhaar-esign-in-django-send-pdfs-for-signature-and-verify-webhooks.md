# Aadhaar eSign in Django: send PDFs for signature and verify webhooks

## Overview

Indian businesses run on signed PDFs: rent agreements, offer letters, NDAs, loan sanction letters. Aadhaar eSign lets a signer sign with an OTP sent to their Aadhaar-linked mobile, and the result is a valid electronic signature under Section 3A of the IT Act 2000. No printer, no courier, no USB token. This tutorial adds Aadhaar eSign to a Django project using the SignYu API . SignYu sits in front of a licensed eSign provider (eMudhra), so you work with a plain REST API and webhooks instead of gateway encryption and redirects. By the end you will have: A Contract model that tracks each document. A view that uploads a PDF, adds signers, and sends it. A webhook view that verifies the HMAC signature and updates the model. A view that downloads the completion certificate. There is also a Django guide at signyu.com/aadhaar-esign-api/integrations/django . Prerequisites Python 3.9+ and Django 4.2+ (the code also works on Django 5). Create an API key under Developers at https://signyu.com/app/developers . There is no sandbox, because every signature is a real Aadhaar eSign.
