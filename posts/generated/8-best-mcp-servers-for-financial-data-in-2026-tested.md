Massive MCP (formerly Polygon.io): best for US real-time and tick data Massive is the new name of Polygon.io, and its MCP server (401 stars, MIT, marked "experimental") takes an unusual approach: instead of one tool per endpoint, it exposes three, search_endpoints , call_api and query_data . The model searches the API docs, then calls what it needs. There's also a hosted version at mcp.massive.com . Docs only. That three-tool design is worth copying. A server with 100 tools sends 100 tool descriptions to the model before the first question. Massive sends three, and the model discovers the right endpoint on demand. It costs an extra call per question, but it keeps the context window free for the actual data.
