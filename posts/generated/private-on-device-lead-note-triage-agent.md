# Private On-Device Lead & Note Triage Agent

## Overview

The Problem Managing unstructured consultation notes and inbound client leads often takes hours of manual review. Relying on public cloud AI APIs to parse sensitive notes introduces data privacy risks, potential data leakage, and recurring API costs. The Solution I built a private, local-first triage agent that automatically ingests raw meeting notes or audio transcripts, parses key metadata (client name, core requirements, budget, priority level), and outputs formatted JSON ready for immediate logging—all while keeping sensitive data secure. Architecture & Schemas Ingestion: Raw text prompt or consultation transcript. Processing Engine: Relevance AI node pipeline configured for schema-based extraction. Output: Structured JSON containing prioritized action items and client details.
