# Resume Starter Pack: Visual Editing + Automated PDF Releases

## Overview

Resume Starter Pack Resume Starter Pack is an open-source tool for creating and maintaining your resume in a local visual editor. Edit in your browser, track changes with Git, and generate PDFs automatically—without writing LaTeX. 🔗 Explore the repository What can you do with it? Edit with a live preview Update your contact details, summary, experience, projects, skills, and education using simple form fields. See changes immediately, then click Save changes to save them locally. Reorder with drag and drop Arrange entries and sections using drag handles. Keyboard users can reorder items with the Up and Down keys. Customize the layout Adjust the resume to suit your content: Letter or A4 paper size Font family and text size Page margins and line spacing Gaps between sections and entries An overflow indicator shows when content exceeds one page. PDF export also checks the page count, helping you catch layout issues before publishing. View a clean preview Click Resume only to view the saved resume without the sidebar or toolbar, using the same template as the editor preview. Generate versioned PDFs Publishing a GitHub release triggers automatic PDF generation. For example, a release tagged v1.0 builds resume-1.0.pdf , verifies that it contains exactly one page, and attaches it to that release. Each release keeps its own PDF, so previous versions remain available to download. Regular pushes and pull requests validate the source without generating a release PDF.
