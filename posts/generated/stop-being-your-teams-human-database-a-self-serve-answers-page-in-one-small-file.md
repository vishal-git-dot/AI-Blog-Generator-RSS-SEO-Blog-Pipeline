# Stop being your team's human database: a self-serve answers page in one small file

## Overview

If you have database access, you know the message: "Got a sec? Can you pull a number for me?" Sales wants a number. Support wants a number. Finance wants theirs by five. Each one is small. Together they eat the day, and every one costs you the time it takes to get back into what you were doing. This post builds the smallest thing that removes you from that loop: one page where a colleague types a question and gets an answer they can check without you . What "an answer they can check" means If the page only shows a sentence, people will come back and ask you to confirm it. So every answer needs three parts: The answer in words. The rows it came from. The query that ran , folded away for anyone who wants it. With those three on screen, "is this right?" stops being a question for you. The whole app One Flask file. It serves a page and proxies questions to FactQL , which returns the answer, the rows and the query in one JSON response. The page shows the sentence, draws the rows as a table, and tucks the query under "The query that ran". Four things worth getting right Keep the key on the server. The browser talks to /ask , never to the upstream service. A key in page code can be read by anyone who opens the page. Write values with textContent , not innerHTML . Answers and rows are data. Treat them as text so nothing in a cell can run as markup. Use a read-only database user when you point this at your own database instead of the sample. Handle 429. The sample key allows only a couple of questions a minute per IP, so the proxy passes the wait time on instead of failing silently. Pointing it at your own data Set FACTQL_API_KEY to your own key and the same file works against your data: an uploaded CSV or Excel file, or a PostgreSQL or MySQL database connected with a read-only user. The free plan needs no card. When not to do this If people ask the same five questions every week, a dashboard is the better tool. This page is for the long tail: the questions nobody predicted, which are exactly the ones that land in your DMs. What's the "quick question" you get asked most often?
