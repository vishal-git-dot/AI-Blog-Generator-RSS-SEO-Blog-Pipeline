# EU CCAT Project Develops Open-Source Tools for Continuous Security Assessment

## Overview

The EU-funded Cybersecurity Certification and Assessment Tools project, known as CCAT , is developing an open-source toolchain for continuous security assessment of digital products and services. Coordinated by Masaryk University under Horizon Europe, the project aims to help producers, consumers and regulators assess cybersecurity in the context of evolving EU rules, including the Cybersecurity Act and Cyber Resilience Act. The central idea is practical: security assessment should not end when a product receives a certification. Digital products, software dependencies and threat landscapes change over time. CCAT is adapting four existing open-source tools for real-world use across transport security, cryptographic implementations, embedded hardware and certification information. The project's official CCAT project website describes this work as a route to more transparent and repeatable cybersecurity assessment. What the CCAT toolchain covers CCAT brings together tools that address different parts of the security-assessment process. They are not a single scanner or a one-click compliance product. Instead, the tools target distinct technical questions that can arise when building, buying or operating digital products. TLS-Scanner analyses the security of TLS clients and servers. Built on TLS-Attacker, it can help identify issues in the protocol configurations used to protect communications. SCRUTINY analyses cryptographic implementations in hardware and software. Its intended evaluation environments include smartcards, Trusted Platform Modules and embedded libraries. ALVIE automates security evaluation for embedded hardware architectures by bridging formal verification and vulnerability research. The project plans support for FPGA and RISC-V environments. sec-certs collects and structures certification artefacts from Common Criteria, EUCC and FIPS 140. It also exposes links to known CVEs, improving visibility into the certification landscape. Why continuous assessment matters for businesses The Cybersecurity Act and Cyber Resilience Act are part of a changing European cybersecurity environment. CCAT is designed to support assessment and alignment with related regulatory guidance, but it does not replace a legal determination, a certification decision or an organisation's own security work. For businesses, the potential value is in making security evidence more repeatable. Rather than treating a security review as a one-time procurement or release activity, teams can use relevant assessment tools during product development, technical due diligence and ongoing maintenance. That can make it easier to identify issues earlier and create a clearer record of what was reviewed. Open-source availability can also lower the barrier to evaluating suitable tools before committing to proprietary software. It does not make implementation cost-free. Teams still need the technical capability to run assessments, interpret results, prioritise remediation and document decisions.
