# The Relevance of Software Engineering in Web Applications

## Overview

Introduction Software engineering plays an important role in the development of modern web applications. Today, web applications are used in almost every area of life, including education, banking, communication, healthcare, entertainment, and online shopping. Developing a successful web application requires more than just writing code. It involves proper planning, designing, testing, security, and maintenance. These activities are part of software engineering. However, with the introduction of Artificial Intelligence (AI), developers can now create applications by simply describing what they want. This practice is commonly known as vibe coding. Although vibe coding makes development faster and easier, depending entirely on AI without understanding the generated code can create serious problems. This article discusses the relevance of software engineering in web applications and highlights the dangers of vibe coding and developing WebApps without proper software engineering practices. 1. Meaning of Software Engineering Software engineering is the systematic application of engineering principles, methods, and techniques to the development, testing, operation, and maintenance of software. It is not just about writing code. It involves several stages: Requirement analysis. System design. Coding and implementation. Software testing. Deployment. Maintenance. For example, when developing an online shopping application, developers must plan how customers will register, log in, search for products, make payments, and track their orders. Without proper planning, the application may contain errors and security problems. 2. Relevance of Software Engineering in Web Applications Software engineering is important in WebApps for several reasons. A. Security Web applications often store personal information such as names, passwords, addresses, and payment details. Software engineering helps developers protect this information against unauthorized access and cyberattacks. B. Reliability A good web application should perform its functions correctly. Software engineering encourages proper testing to identify and correct errors before the application is released. C. Easy Maintenance Web applications need regular updates and improvements. Properly organized code makes it easier for developers to correct errors and add new features. D. Scalability Scalability is the ability of an application to handle an increasing number of users. Proper software design helps an application grow without constantly failing. E. Cost Reduction Planning and testing help developers identify problems early. This reduces the cost of correcting errors after an application has been released. F. Better User Experience Software engineering helps developers create applications that are easy to use, responsive, accessible, and efficient. 3. Understanding Vibe Coding Vibe coding is a modern approach to software development where a person uses ordinary language to describe an application and depends on Artificial Intelligence tools to generate much of the code. For example, a person may tell an AI tool: "Create an online shopping website where customers can register, buy products, and make payments." The AI tool may generate HTML, CSS, JavaScript, and other parts of the application. Vibe coding can help beginners learn programming, build prototypes, and complete simple tasks faster. However, problems arise when developers accept AI-generated code without understanding, reviewing, or testing it. 4. Demerits and Dangers of Vibe Coding Although vibe coding has advantages, it also has several disadvantages. A. Security Vulnerabilities AI-generated code may contain security weaknesses. For example, a login system may fail to protect user accounts properly or may allow unauthorized users to access restricted pages. B. Poor Code Quality AI can generate code that works but is poorly organized. It may contain repeated code, unnecessary functions, and complicated structures. C. Lack of Proper Testing Some developers assume that an application is ready simply because it opens successfully. However, the application may still contain errors that appear when users interact with it. D. Database Problems AI-generated applications may have poorly designed databases. This can cause duplicated information, incorrect relationships, and difficulties managing records. E. Overdependence on AI Developers who depend entirely on AI may fail to develop their programming and problem-solving skills. They may struggle to identify and correct errors without AI assistance. F. Privacy Risks Sharing passwords, API keys, or private customer information with unapproved AI tools can expose sensitive information. G. Difficult Maintenance When developers do not understand the code generated by AI, updating and improving the application can become difficult. H. False Confidence An application may look professional because it has attractive colours, buttons, and dashboards. However, its appearance does not guarantee that it is secure, reliable, or functional. 5. Dangers of Developing WebApps Without Software Engineering Developing web applications without following proper software engineering practices can lead to serious problems. Some of these dangers include: Data breaches: Private customer information may be exposed to unauthorized people. Financial losses: Poorly developed payment systems may cause incorrect transactions. System failure: Applications may stop working when many people access them. Data loss: Poor database management may result in missing or damaged information. Poor performance: Unorganized code may make an application slow. Unauthorized access: Weak security may allow people to access restricted accounts. High maintenance costs: Poorly structured applications are difficult to update. Loss of customer trust: Users may stop using applications that frequently fail or expose their information. These problems show that developing a WebApp is not just about making it attractive. It must also be secure, reliable, and functional. 6. How Software Engineering Can Prevent These Problems Developers can reduce these risks by following proper software engineering practices. 1. Requirement Analysis: Developers should understand what the application is expected to do before development begins. 2. System Design: Developers should plan the structure of the application, database, and relationships between different components. 3. Proper Coding: Developers should write clean, organized, reusable, and understandable code. 4. Software Testing: Applications should be tested to identify errors and confirm that their features work correctly. 5. Database Security: Developers should protect stored information through appropriate access controls and secure database practices. 6. Code Review: Code should be reviewed to identify errors and security weaknesses. 7. Regular Maintenance: Applications should receive regular updates, corrections, and security improvements. 8. Responsible Use of AI: AI should be used as an assistant rather than a replacement for programming knowledge and software engineering practices. 7. Relationship Between Artificial Intelligence and Software Engineering Artificial Intelligence is changing the way software is developed. AI tools help developers generate code, understand programming concepts, and complete tasks faster. However, AI does not remove the need for software engineering. Developers must still understand, review, test, and improve the code generated by AI. For example, AI can generate a registration form, but the developer must ensure that user information is validated, passwords are properly protected, and the database stores information correctly. The best approach is to combine AI tools with software engineering principles. Conclusion Software engineering is an essential part of developing successful web applications. It helps ensure that applications are properly planned, designed, developed, tested, secured, and maintained. Although vibe coding has made software development easier and faster, depending completely on AI-generated code without proper understanding and testing can create serious security, privacy, performance, and maintenance problems. A professional web application should not be judged only by its appearance or how quickly it was developed. Its quality should also be measured by its security, reliability, performance, and ability to meet users' needs. Therefore, developers should not abandon software engineering because of Artificial Intelligence. Instead, they should use AI alongside proper engineering practices. The future of web development should not only be about generating code quickly, but about building applications that are secure, reliable, useful, and sustainable.
