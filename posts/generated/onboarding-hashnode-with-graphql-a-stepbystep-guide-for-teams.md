# Onboarding Hashnode with GraphQL: A Step‑by‑Step Guide for Teams

## Overview

Integrating a new publishing platform can feel like a mini‑project on its own: you need access tokens, you have to learn the API surface, and you must prepare the first batch of content that fits the new audience. This article walks through a real‑world onboarding flow for Hashnode, covering everything from token generation on a restricted IP to publishing the first three technical articles via GraphQL. The process is written for a small dev‑ops team that already uses Telegram for community management, so you’ll see concrete examples that you can copy‑paste into your own workflow. 1. Why Hashnode? Hashnode is a developer‑centric blogging platform with built‑in SEO, community comments, and a GraphQL API that makes programmatic publishing painless. For teams that already produce content for Telegram groups or Discord, moving that knowledge base to Hashnode can: Increase discoverability through Google’s index of developer blogs. Provide a clean, markdown‑first editor that syncs with your existing docs. Allow you to automate posting, updates, and cross‑posting via GraphQL mutations. 2. Prerequisites Before you start, make sure you have the following: The owner’s Hashnode account credentials (in our case dongjiahu2026@gmail.com ). Access to the owner’s local machine . The API token must be generated there because Hashnode’s backend (running on Vercel) blocks requests from our SG‑based server IP. A GraphQL client (e.g., curl , Postman, or a Node library like graphql-request ). The three draft articles saved as markdown files ( draft1.md , draft2.md , draft3.md ). 3. Generating the API Token on the Owner’s Machine The token is a one‑time secret; it appears only once in the UI, so copy it immediately and send it via a secure channel (Telegram DM in our workflow). Open a browser on the owner’s computer and log in to hashnode.com with dongjiahu2026@gmail.com . Click the avatar in the top‑right corner → Settings . In the left navigation, choose Access Tokens . In the Generate API Token field, type a descriptive name such as aigb_prod_key_v1 and click Generate . Copy the token that appears, then paste it into a Telegram private message to the team lead. Tip: The token is visible only once. If you lose it, you’ll have to regenerate a new one. 4. GraphQL Basics: Posting a Draft Hashnode’s GraphQL endpoint is https://gql.hashnode.com/v2 .
