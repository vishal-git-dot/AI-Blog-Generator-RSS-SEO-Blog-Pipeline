# How to get German job listings from the Arbeitsagentur as JSON or CSV (Python and n8n)

## Overview

The Bundesagentur für Arbeit (Federal Employment Agency) runs Germany's largest job board, the Jobsuche . Its search is also reachable as data, which makes it the best free starting point if you need German job listings for a job board, a market report, a recruiting dashboard or just a daily alert for yourself. This guide shows how to get those listings filtered by keyword, city, radius and date, as JSON or as a CSV file, and how to turn that into a daily alert. All numbers below are from real runs on 8 November 2026. Disclosure: I built the tool used below, the Job Search API on Apify. It calls the official public job APIs; you don't need an Arbeitsagentur account. Step 1: one city, one role, last 7 days curl -X POST "https://api.apify.com/v2/acts/fast_data_asap~job-search-api/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "keywords": "Data Analyst", "location": "Hamburg", "radiusKm": 25, "postedWithinDays": 7, "sources": ["arbeitsagentur"], "maxJobsPerSource": 20 }' This took 6.3 seconds and returned 7 jobs published in the Hamburg area during the previous week. Each one is a flat row: { "title" : "Data Analyst (m/w/d)" , "company" : "fabplus GmbH" , "location" : "21129, Hamburg, Germany" , "remote" : false , "employmentType" : "full-time" , "postedAt" : "2026-11-03T00:00:00+00:00" , "url" : "https://www.arbeitsagentur.de/jobsuche/jobdetail/…" , "source" : "arbeitsagentur" , "sourceJobId" : "…" , "tags" : [], "salaryMin" : null } Two things stood out in those 7 rows: Two of the seven were the same client job, advertised by service providers. "Data Analyst (d/f/m) for AIRBUS" and "Data Analyst (d/m/w) für AIRBUS" were posted by two different companies. If you count jobs per employer, you need to account for ads that name the actual client only in the title. Keyword matching is broader than the title. The search also returned a "Client Partner Banking" and a "Senior Business Analyst" role, presumably because the agency's own search matches tags and descriptions. If you need strict title matches, filter afterwards (see step 3). Step 2: all of Germany, as CSV Leave location empty to search the whole country. Add &format=csv to the endpoint and you get a CSV file instead of JSON, ready for Excel or Google Sheets: curl -X POST "https://api.apify.com/v2/acts/fast_data_asap~job-search-api/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN&format=csv" \ -H "Content-Type: application/json" \ -d '{"keywords": "Python", "location": "", "postedWithinDays": 7, "sources": ["arbeitsagentur"], "maxJobsPerSource": 50}' \ -o python-jobs.csv My run hit the limit of 50 jobs in 7.5 seconds , so the real number of new Python listings that week is higher. Raise maxJobsPerSource for a complete pull. Step 4: a daily job alert in n8n Schedule Trigger : every weekday at 07:00.
