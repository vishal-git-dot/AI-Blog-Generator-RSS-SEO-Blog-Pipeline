# Robotic therapy for stroke patients

## Overview

弱視トレーニングは「続かない」が最大の敵だった——AI×ロボットのリハビリ報道から考える、VRゲームという選択肢 1. きっかけは、リハビリの「人手不足」ニュース MIT Technology Reviewが報じた「Robotic therapy for stroke patients」。 脳卒中を起こした人のうち、毎年500万人が長期的な障害を抱えている。しかし理学療法士の数は足りず、必要なケアに行き渡らない。そこで注目されているのが、AIと人間のセラピーを組み合わせる新しいアプローチだ。元MITポスドクで現在は助教を務めるJohannes Lachner氏らの取り組みが紹介されている。 このニュースの本質は「ロボットが療法士を置き換える」ではない。 反復トレーニングという、地味で、量が必要で、どうしても続かない工程を、テクノロジーが支える という点にある。 そしてこの論点は、視覚のトレーニングにもほぼそのまま当てはまる。エンジニアとしてこの記事を読んだとき、僕が最初に思ったのは「これはリハビリのUX問題だ」ということだった。 adherence（継続率）が低いのは、患者の意志が弱いからではない。 フィードバックループが遅く、報酬が遠く、退屈だという設計の問題 だ。だったら、その設計を組み直せばいい。 2. 弱視（lazy eye / amblyopia）の訓練が抱えるジレンマ 弱視や関連する両眼視の問題に対して、長く使われてきたのがアイパッチによる遮蔽だ。優位眼を隠し、弱い目を単独で使わせる。理屈は明快で、実績もある。 ただし、現実には次の壁がある。 子どもにとって地味で、大人にとっても退屈。継続が難しい 「片目を隠す」訓練なので、両目を同時に使う力（両眼視）を直接は鍛えない 家庭で毎日一定量をこなすには、モチベーションの設計が要る つまり、リハビリと同じ「継続の問題」を抱えている。ここで一度、システムとして整理してみる。弱視訓練を「入力（視覚刺激）→ 処理（脳の両眼統合）→ 出力（日常動作）」というパイプラインとして見ると、従来の遮蔽は 入力段で片眼を落とす 操作にあたる。一方、両眼視の再学習は 処理段の再配線 を狙うもので、必要な刺激の出し方が根本的に違う。この違いを、家庭のリビングでどう再現するか——それが設計課題になる。 3. そこで、反復をゲームにする Seven SportzがMeta Quest向けに開発した AmblyoPunch は、この「継続」にゲームの力でアプローチするVRトレーニングゲームだ。 ゲームの基本はシンプル。飛んでくるガボールパターン（縞模様）のコインを、コントローラーやハンドトラッキングでパンチして得点にする。赤いトゲが迫ってきたらよけてかがむ。ハートは3つ、すべて失うとリスタート。ワールドは村から都市、宇宙、月、火星、金星へと進み、オブジェクトは速く、小さくなり、トゲは大きくなる。 単なる的当てではない。裏側に4段階のダイコプティック（両眼分離提示）設計がある。 Stage 1 単眼ウォームアップ — ターゲットを弱い目にのみ提示 Stage 2 抑制の解除 — 優位眼の映像を強く暗く／白っぽくし、抑制をゆるめる Stage 3 再バランス — 明瞭さを徐々に回復させ、両眼の寄与をそろえる Stage 4 融像トレーニング — Panumの融像領域内のわずかなずれを与え、1つの3D知覚に統合する練習 進行はパフォーマンスでゲートされる。直近10回の結果でおおむね70%以上、斜視（strabismus）のプロファイルでは最終融像の前に80%以上が目安とされている。 エンジニア目線で面白いのは、これが 適応型の難易度制御（adaptive difficulty） になっている点だ。ゲームの世界では、プレイヤーのスキルに合わせて敵の強さを動的に変える仕組みが当たり前になっている。AmblyoPunchはその考え方を、視覚刺激の提示パラメータにそのまま流用している。閾値に近い負荷をかけ続けることで、学習を最大化しようという発想だ。直近10セッションの窓で成功率を見るのは、ノイズの多い単発結果に引っ張られないための 移動平均的な平滑化 だと読める。 Stage 2の「優位眼を暗くする」処理も、技術的には興味深い。片眼に強い信号、もう片眼に弱い信号を同時に提示し、脳が強い方だけを見て弱い方を無視する 抑制（suppression） をゆるめにかかる。VRの両眼分離レンダリングがあるからこそ、左右の目に別々の映像をフレーム単位で出し分けられる。専用ハードなしでこれが家庭に届くのは、Questというプラットフォームの恩恵だ。 4. 「あなたの目」に合わせる設定 同じ弱視でも、弱い目が左右どちらか、重症度、斜視のタイプは人によって違う。AmblyoPunchはそこを設定で合わせる。 弱い目: 左 / 右（逆に選ぶと効果が反転するため、ここは正確に） 重症度: 軽度 / 中等度 / 重度 → ターゲットのサイズ、速度、ステージの長さが変わる 斜視: 内斜視 / 外斜視 → Stage 4の視差・輻湊シフトが変わる 基本は 自動モード が推奨で、カスタム（手動での単眼／両眼提示、融像トグルの操作）は上級者向けだ。 設定項目を並べてみると、これは一種の キャリブレーション・パラメータ だとわかる。弱い目を「左/右」で切り替えるのは単なる左右反転ではなく、刺激を届けるチャネルの選択だ。逆に設定すると、鍛えたい目ではなく優位眼をさらに強化してしまう。重症度プリセットはターゲットのサイズ・速度・ステージ長をまとめて調整する。つまり「難易度カーブの初期値」を症状に合わせて差し替えているわけだ。手動カスタムを上級者向けに置いているのも妥当で、誤った融像トグルは学習を妨げかねない。 5.
