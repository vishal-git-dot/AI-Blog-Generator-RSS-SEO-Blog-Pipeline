# How to run an on page SEO audit for a list of URLs

## Overview

Checking titles, meta descriptions, headings, canonicals and noindex tags page by page in a browser is fine for one landing page. For a site with two hundred pages, or a client list of competitor pages, you want one table: every page, a score, and a list of what to fix. On Page SEO Audit by Hay Equipos does that. Give it a list of URLs, or one start page and let it crawl the site, and it returns one row per page with a score, every issue it found (error, warning or notice) and a fix hint for each. What it checks Title, meta description, H1 and heading structure, canonical, indexability (noindex, the X-Robots-Tag header and robots.txt), hreflang, language, mobile viewport, Open Graph and Twitter cards, structured data ( JSON-LD and microdata), image alt text, thin content, text to HTML ratio, server response time, page weight, redirects, HTTPS and mixed content, favicon, empty links and, optionally, broken links. What you get back One row per page. Trimmed example with illustrative values: { "url" : "https://www.example.com/pricing" , "finalUrl" : "https://www.example.com/pricing" , "success" : true , "statusCode" : 200 , "responseTimeMs" : 380 , "htmlBytes" : 48210 , "score" : 71 , "errorCount" : 1 , "warningCount" : 3 , "noticeCount" : 2 , "title" : "Pricing" , "titleLength" : 7 , "metaDescription" : null , "h1Count" : 2 , "canonical" : "https://www.example.com/pricing" , "isIndexable" : true , "hasViewport" : true , "wordCount" : 412 , "imagesMissingAlt" : 3 , "issues" : [ { "severity" : "warning" , "code" : "title_too_short" , "message" : "The title is only 7 characters." , "fix" : "Use 30 to 60 characters with the main keyword first." }, { "severity" : "warning" , "code" : "description_missing" , "message" : "The page has no meta description." , "fix" : "Add a meta description of 70 to 160 characters that summarizes the page." } ], "auditedAt" : "2026-09-27T06:14:02.518Z" } Every row also has fields such as metaRobots , xRobotsTag , hreflang , openGraph , twitterCard , structuredDataTypes , textToHtmlRatio , internalLinkCount , externalLinkCount , mixedContentCount and hasFavicon . With the link check on, you also get linksChecked and brokenLinks . How the score works: each page starts at 100 and loses 12 points per error, 5 per warning and 1 per notice, with a floor of 0. Broken links count as one error per page. At the end of each run, a site summary is saved in the run's key value store under SUMMARY : pages audited, average score, how often each issue appeared, duplicate titles and duplicate meta descriptions across the pages audited.
