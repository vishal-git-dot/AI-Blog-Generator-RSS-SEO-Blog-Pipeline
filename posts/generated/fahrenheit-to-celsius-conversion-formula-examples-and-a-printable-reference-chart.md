# Fahrenheit to Celsius Conversion: Formula, Examples, and a Printable Reference Chart

## Overview

Temperature conversion is a simple but useful programming and mathematics problem. Whether you are building a weather application, processing sensor data, working with scientific measurements, or following an international cooking recipe, you may need to convert Fahrenheit values into Celsius. The conversion itself requires only a basic mathematical formula. However, understanding the formula, handling rounding correctly, and validating results are important when implementing it in software. In this guide, we will explore the Fahrenheit to Celsius formula, common reference values, practical examples, and a simple JavaScript implementation. 1. Understanding Fahrenheit and Celsius Fahrenheit (°F) and Celsius (°C) are two temperature scales used around the world. The Celsius scale uses 0°C as the freezing point of water and 100°C as its boiling point under standard atmospheric pressure. On the Fahrenheit scale, water freezes at 32°F and boils at 212°F under the same conditions. Because the scales use different zero points and degree intervals, converting between them requires both subtraction and multiplication. 2. Fahrenheit to Celsius Conversion Formula The standard formula is: C = (F - 32) × 5 / 9 Where: F represents the temperature in Fahrenheit. C represents the converted temperature in Celsius. 32 adjusts for the difference between the scales' zero points. 5 / 9 accounts for the difference in degree size. Example: Convert 350°F to Celsius First, subtract 32: 350 - 32 = 318 Then multiply by 5/9: 318 × 5 / 9 = 176.666... Therefore: 350°F ≈ 176.7°C This example is especially useful when converting oven temperatures from recipes that use Fahrenheit. 3. Implementing the Conversion in JavaScript For developers, Fahrenheit to Celsius conversion can be implemented in a single function. function fahrenheitToCelsius ( fahrenheit ) { return ( fahrenheit - 32 ) * 5 / 9 ; } console . log ( fahrenheitToCelsius ( 32 )); // 0 console . log ( fahrenheitToCelsius ( 68 )); // 20 console . log ( fahrenheitToCelsius ( 350 )); // 176.66666666666666 The function returns a numeric result without rounding it. This is generally useful because calculations can retain precision until the final display step. Formatting the Result If you want to display temperatures to one decimal place, use toFixed() : function formatCelsius ( fahrenheit ) { const celsius = ( fahrenheit - 32 ) * 5 / 9 ; return ` ${ celsius . toFixed ( 1 )} °C` ; } console . log ( formatCelsius ( 350 )); // 176.7°C console . log ( formatCelsius ( 212 )); // 100.0°C console . log ( formatCelsius ( 32 )); // 0.0°C One important detail: toFixed() returns a string, not a number.
