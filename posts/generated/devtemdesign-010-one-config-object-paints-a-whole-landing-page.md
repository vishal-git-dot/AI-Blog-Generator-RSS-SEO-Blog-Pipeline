# devtemDesign 0.1.0: one config object paints a whole landing page

## Overview

Every landing page I built started the same way: nav, hero, feature cards, pricing, FAQ, footer, then a day of making it responsive. So I wrote an engine that does that part for me. devtemDesign takes one config object and renders the whole page. No framework, no build step, no dependencies. Two tags and one function call. This post is both an introduction and a reference for v0.1.0 . Try it in 30 seconds <link rel= "stylesheet" href= "https://cdn.jsdelivr.net/npm/devtemdesign@0.1.0/style.min.css" > <script src= "https://cdn.jsdelivr.net/npm/devtemdesign@0.1.0/script.min.js" ></script> <div id= "app-root" ></div> <script> devtemDesign ( " app-root " , { template : " cyber " , logoName : " MYAPP " , heroTitleLine1 : " Declarative UI, " , heroTitleLine2 : " Zero-Config Motion " , heroSubtitle : " One config object. Complete animated landing. " , primaryBtnText : " Get started " , primaryBtnHref : " /docs " }); </script> That gives you a sticky glass navbar, an animated hero, ambient background orbs, reveal-on-scroll, a mobile drawer and a footer. Every section except the hero is optional, and a section only renders when its config key is present. If you want to skip the code entirely, the builder generates a config from a description and lets you edit it live. What's in 0.1.0 7 templates: figsh , cyber , aurora , monochrome , sunset , ocean , and paper (light). Live theming: switch at runtime, add a built-in theme button, or override any design token. New sections: stats with count-up numbers, FAQ accordion, closing CTA, and pricing with a Monthly/Yearly toggle. Interactions: scroll progress bar, active nav link, card spotlight, seamless brand marquee, back-to-top button. A real lifecycle: devtemDesign() returns { setTemplate, destroy } . Accessibility: skip link, focus rings, aria-expanded on the menu, native <details> for FAQ, full prefers-reduced-motion support.
