# A Skipped Test Is a Withdrawal: Make Agent Patches Deposit a Property Before You Freeze a Flake

## Overview

The cheapest way to make an agent patch go green is to skip a test. Most gates allow that skip with no compensating deposit, and then let the skip follow the patch into the next patch in the merge queue. Two weeks later nobody can tell whether the suite shrank because the code got safer or because eleven freezes quietly accumulated. This post proposes a freeze ledger with four blocking rules: a bounded expiry window, a named owner, a compensating property that must actually run against the patch, and a hard ban on inheriting skips across patch boundaries. All four are enforced by a script short enough to read in one pass. The artifact is a policy file plus roughly sixty lines of Python, not a testing framework. 1. The two ways a freeze lies A freeze is a claim that the skipped test was not carrying unique coverage. That claim fails silently in two specific ways. Inheritance. In a merge queue, patch B's gate reuses the artifact from patch A's run. A's skip set rides along, so B is validated against a suite that neither B's author nor B's reviewer chose. The green badge is real; the denominator behind it is not. Withdrawal without deposit. A skipped test stops paying rent. If nothing else asserts its invariant, the patch covers strictly less than the previous commit while reporting the same status. Nothing in a standard CI log distinguishes this from a clean run. Neither failure is loud. Both are visible in one artifact you are probably not writing: the exact set of tests the gate skipped, tied to the commit that skipped them. 2. Step 1: make the freeze a reviewed record, not an inline decorator An inline @pytest.mark.skip lives in the test file, far from the diff a reviewer is reading. Move the decision into one file that changes as its own diff. { "schema" : 1 , "max_window_days" : 14 , "freezes" : [ { "test_id" : "tests/test_billing.py::test_proration_rounding" , "reason" : "order-dependent failure in full suite; passes in isolation" , "owner" : "finley" , "opened" : "2026-10-12" , "expires" : "2026-10-26" , "invariant" : "proration amount never decreases when the period lengthens" , "compensating_property" : "tests/props/test_proration_props.py::test_monotonic_in_period" , "reused_property" : false } ] } Six of those fields are boring on purpose. The 14-day window is a policy choice, not a discovered constant. Pick a number your team can staff, then let expiry force re-attestation. 3. Where the agent, and the hosted run, fit The drafting step is where a model helps. Give it the invariant text and the frozen test, and ask for three candidate properties plus the one input class it would not generate. It will produce plausible candidates; it will not tell you which are weak, so the distinct-input counter and the diff check stay yours. Limitations and who should not adopt this The ledger needs a merge queue or at least a shared branch to be meaningful. A solo repo with direct pushes gets the bookkeeping cost without the inheritance check. prop_samples.json counts distinct repr values. That catches the single-input property, not a weak generator that produces near-duplicates. The property-file-in-diff rule assumes one property per invariant. Splitting an invariant across two files needs a manual note in the ledger. If your flakiness comes from shared staging infrastructure, freezing just relocates the flake. Fix the lane or move the test to a nightly run. Teams that cannot staff a two-week expiry review should delete the flaky test outright and write the property. A freeze nobody revisits is worse than a deletion, because deletion is honest. 9. What to measure after a week Three numbers, all cheap: how many existing freezes fail the deposit check, the median age of open freezes, and how many inherited skips the queue script refused. I am not going to invent those numbers for you — they depend entirely on how much debt your suite is already carrying. Start with one repository and one rule: no freeze without a property that ran. Everything else in this post is enforcement around that sentence.
