# Generating AutoCAD R12 (AC1009) ASCII .DXF Files in Pure TypeScript: 8 AIA Layers, $INSUNITS Inches, and Screen-to-CAD Arc Math

## Overview

Real drafting software expects true 1:1 US inch coordinates, clean right-handed Cartesian geometry, separated AIA-style layers with distinct AutoCAD Color Index (ACI) colors, and valid DXF header and table records that never trigger a file-recovery prompt.
