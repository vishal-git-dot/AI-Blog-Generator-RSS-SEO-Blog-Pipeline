# AquaSort: Sort colourful liquids into tubes

## Overview

Sort colourful liquids into tubes Pour coloured liquids between tubes until every colour collects in a single vessel. The rules take ten seconds to learn, and the levels never end — the difficulty grows on its own: more colours, locked tubes, stars for thrifty moves. There is a daily challenge with a set task, achievements, a skin collection and cloud saving of your progress. We build it as a single canvas codebase with no engine, and publish it through the Playgama Bridge SDK — the same build goes to a dozen portals, with progress stored through the platform SDK and the interface in 14 languages.
