# The Blindfolded Hike That Explains How Machines Learn

## Overview

Picture this: someone blindfolds you halfway up a hillside and asks you to find the lowest point. You cannot see a thing. All you can do is feel which way the ground tilts under your shoes, take one step, and feel again. That exact walk is what every machine learning model performs, over and over, while it is being trained. Its hillside is just built out of numbers instead of rocks and grass. By the end of this post you will understand that walk well enough to read it in code, not just picture it. What a model is actually doing when it "learns" Say you are building a model to guess house prices. You feed it a house, and it spits out a number: maybe $300,000. The real price was $340,000. Your model was wrong by $40,000. That wrongness has a name: a loss function (sometimes called a cost function). It is one number that says how bad the current guess is. Zero means a perfect guess. A model's guess is controlled by adjustable numbers inside it, called parameters or weights. Learning means searching for parameter values that make the loss as small as possible, across every example the model has seen. Plot the loss as a graph, with height meaning "how wrong," and you get an imaginary hillside. The lowest point is the best the model can do. The slope under your feet, which direction makes the loss grow fastest and by how much, is called the gradient. Put it together: gradient descent means feel the slope, step downhill, feel again, repeat, until you cannot go down any further. In one line of pseudocode: parameters = parameters - step_size * gradient(loss, parameters) Why step size changes everything Tiny steps are safe but slow. Giant steps can overshoot the bottom entirely and land you worse off than where you started, then overshoot again on the way back. The chart above is a real, computed run starting five units from the bottom. A step size of 0.05 is still almost two units away after ten steps. A step size of 0.30 settles near zero in about five steps. A step size of 1.05 never settles, it swings further out with every step. The hill is smooth: its slope never changes faster than a fixed rate L, here L = 1, so step size 1/L = 1 is mathematically safe. x next ​ = x current ​ − (step size) × (slope at x current ​ ) Walking it out: 4, 3, 2, 1, 0, the bottom reached in exactly four steps. The error after each step: 2.5, 1.5, 0.5, 0. Because the hill is smooth and convex (shaped like a single bowl with one lowest point), there is a proven ceiling on the error after k steps: error after k steps ≤ k 8 ​ That bound decays like "one over k": roughly ten times more steps for ten times more accuracy. This method is not new either. Augustin-Louis Cauchy described it in a short note in 1847, while computing a star's orbit using algebra instead of harder equations by hand. Where this breaks down Real loss surfaces are rarely one clean bowl. A model can land in a shallow dip, a local minimum, and stop there even though a deeper valley exists elsewhere. Picking L exactly, the way we did above, only works because the example was simple. Real step sizes are usually tuned through experiment instead. And a real model's hill has one direction per parameter, sometimes millions of them, which is exactly why plain gradient descent gets replaced by its smarter cousins at scale. One line to take with you Every model that has ever learned anything has done nothing more than take small, careful steps downhill until it could not go any lower, the same walk Cauchy described in 1847, just running in a training loop instead of an astronomer's notebook. Words used in this post Gradient descent: a method for finding the lowest point of a hill of numbers by repeatedly stepping downhill. Loss function (cost function): a single number that measures how wrong a model's current guess is. Parameter (weight): one of the adjustable numbers inside a model that changes its guesses. Learning rate: how big a step the model takes downhill at each try. Local minimum: a dip in the hill that looks like the bottom but is not the lowest point overall. Convergence: the point where the steps stop improving the guess by any meaningful amount. Convex: shaped like a single smooth bowl, with exactly one lowest point.
