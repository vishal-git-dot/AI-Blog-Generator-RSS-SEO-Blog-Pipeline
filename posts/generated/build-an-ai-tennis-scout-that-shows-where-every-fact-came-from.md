# Build an AI tennis scout that shows where every fact came from

## Overview

A useful tennis scout should be able to answer a follow-up: “Which matches support that statement?” If the answer is another paragraph of confident prose, the scout is difficult to trust. If the answer is four match links, a cutoff timestamp and a calculation you can repeat, you have something you can put in front of a reader. This project combines two Actors and a language model. The match lookup provides the target and its stored pre-match ratings. Player history provides earlier results. Python turns them into a small evidence ledger. AI chooses the most useful entries, and a deterministic renderer prints those facts with their source links. Disclosure: I maintain the CrawlPlant Actors used here. The illustrated report is a historical reconstruction for Sinner–Zverev at Wimbledon 2026. It is not an archived prediction published before the final. The illustrated evidence selection is editorial; a paid model call was not used to generate this exported example. What the reader gets The source export contains five Sinner matches. One is the target final, so it cannot count as prior form. Four earlier completed matches remain. It contains no eligible prior Zverev matches. That asymmetry belongs on the card. Calling the result “Sinner's last ten” or filling Zverev's side with a guessed recent record would make the presentation neater and the report worse.
