# Hyperdocs: An AI Documentation Platform That Keeps Up With Your Product

## Overview

Hyperdocs is an AI documentation platform for SaaS teams. It helps you create docs, keep them accurate, and see what’s missing. What you can publish Everything lives in one place: Product docs: guides, onboarding steps and feature pages Help center: articles where customers can find answers API docs: guides and endpoint references Changelog: release notes and product updates Three ways to get started You don’t have to start from code. Write: use the visual editor to build and organize articles. Generate: connect GitHub and get editable drafts based on your product and code. Migrate: import your existing docs, including from Mintlify, and keep refining them. Keeping docs current This is the hard part, and Hyperdocs has three tools for it: GitHub Sync: shows which pages may be affected after a code change. Docs Audit: finds missing and outdated documentation. You can run it manually or on a schedule. Docs Agent: drafts new pages, edits existing ones or fills gaps. Your team reviews every update before it goes live. Helping users find answers Answer Agent: answers visitors’ questions using your published docs and links them back to the source pages. Analytics: shows what people search for, which searches return nothing and what readers think of each page. Multilingual docs: translate and publish in more than one language. AI and SEO visibility: structured pages that search engines and AI tools can find and use. Your code stays under your control Hyperdocs connects to your repository with read-only access. Per the site, your code isn’t used to train AI models and repository secrets aren’t read. Who it’s for Product teams, technical writers, engineering teams and customer support teams, so everyone who owns the docs can work from the same place. Try it You can publish docs in minutes with no credit card. Start at hyperdocs.io.
