# Criando um chat inteligente com React, .NET e Microsoft Foundry

## Overview

Quase toda conversa sobre IA com cliente chega no mesmo pedido: "quero um ChatGPT da empresa" . Um chat com a cara da marca, que responde do jeito certo e que não manda dado sensível para qualquer lugar. E quase toda primeira tentativa que eu vejo comete o mesmo erro: o front chama o modelo direto, com a chave de API dentro do JavaScript. Funciona na demo. Em produção, é chave vazada, prompt de sistema que qualquer um altera pelo DevTools e conta surpresa no fim do mês. Neste artigo eu mostro como eu monto esse chat do jeito certo: React no front, uma API .NET 10 no meio e o Microsoft Foundry (o antigo Azure AI Foundry) com o modelo gpt-5.4-mini . Resposta em streaming, autenticação sem chave e as proteções que separam uma demo de um produto. A arquitetura O código completo está no meu GitHub: hgmauri/sample-chat-react-foundry . São três peças: chat-web : React com TypeScript (Vite). Só conversa com a sua API, nunca com o modelo. Chat.Api : Minimal API em .NET 10. Guarda o prompt de sistema, valida a entrada, controla custo e faz o streaming. Microsoft Foundry : hospeda o deployment do gpt-5.4-mini . A API autentica com Entra ID, sem chave. Por que o modelo mini? Para chat de atendimento, assistente técnico e FAQ, ele entrega qualidade de sobra com latência e custo bem menores que os modelos maiores. Comece pelo menor modelo que resolve o problema e só suba de modelo quando os dados mostrarem que precisa. Preparando o Foundry No portal do Foundry ( ai.azure.com ), crie um projeto e faça o deploy do gpt-5.4-mini . Depois, dê ao seu usuário a role Cognitive Services OpenAI User no recurso.
