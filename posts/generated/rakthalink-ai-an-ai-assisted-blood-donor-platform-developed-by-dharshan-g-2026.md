# RakthaLink AI: An AI-Assisted Blood Donor Platform Developed by Dharshan G (2026).

## Overview

In critical medical emergencies, finding a voluntary blood donor quickly and reliably can save a life. Traditional registries often suffer from outdated contact lists, lack of privacy for voluntary donors, and no clear way to rank donors based on biological compatibility and geodesic distance. To solve this challenge, I developed RakthaLink AI in 2026 — an intelligent, privacy-first coordination platform connecting voluntary blood donors and requesters. 🌐 Live Platform & Source Code Live Web Application: https://rakthalink-ai.vercel.app GitHub Repository: https://github.com/dharshang317-cyber/Rakthalink-ai Developer: Dharshan G (2026) 🩸 Key Innovations & Features 3-Step Mathematical Matching Engine: Evaluates red blood cell biological compatibility matrices. Calculates geodesic proximity using the Haversine Distance Formula to rank nearby available donors with a transparent 0–100 Platform Match Score . WhatsApp-Style Real-Time Interactive Chat: Requesters and donors can coordinate hospital blood bank visits, arrival timings, and requirements instantly through a built-in WhatsApp-styled messaging interface. Automated Transactional Emails with 1-Click Action Buttons: Donors receive an automated email notification: "You have been got the request from [Requester Name]" containing direct Accept and Cancel action buttons. Requester receives real-time confirmation as soon as a donor accepts or cancels. Privacy-Gated Mutual Consent Protocol: Donor phone numbers and private contact details remain masked until the donor explicitly reviews and accepts the request. 🛠️ Architecture & Tech Stack Frontend: React 19, Vite, Tailwind CSS, Google Identity Services OAuth 2.0 Backend: Node.js, Express, Nodemailer, REST API Gateway Database: MongoDB Atlas (Geospatial 2dsphere Indexing) Security: Helmet, Rate Limiters, JWT Authentication RakthaLink AI demonstrates how modern web technologies and ethical AI assistance can streamline voluntary healthcare coordination and save lives.
