# Show DEV: NIB 1.0.0 — my free visual 2D & 3D game engine with JavaScript and web export

## Overview

Hi DEV! I'm Murad Mammadov (MooradXO) . Over the past several months, I've been building NIB , a visual game editor and engine for making 2D and 3D games with JavaScript. NIB 1.0.0, the first stable release, is now available. The idea is to keep scene building, gameplay, character animation, effects, testing and browser export in one visible workspace. You can start with an empty scene or open a playable starter game and change it. Download NIB on itch.io · Stable 1.0.0 release on GitHub The trailer above contains actual gameplay and editor footage captured from the distributed 1.0.0 release. From a scene to a playable game My intended workflow is: Build the scene: place models, sprites, lights and reusable prefabs; organize entities and components in the Hierarchy and Inspector. Give it rules: use the built-in controllers and write JavaScript gameplay, with script parameters exposed in the Inspector. Add motion and atmosphere: work with rigs, animation clips and state graphs, layered effects, spatial audio and game UI. Test: switch into Play, check the Console and Profiler, then return to editing. Share: export a Single HTML game or a Web Project ZIP for hosting. Players of a hosted exported game do not need to install NIB or Node.js. Relay Foundry: first-person movement, animated enemies, interactions and a mission objective. What can you build with it? The release includes ten playable starter games and six rendering/animation showcases . These demonstrate working combinations of the tools: 2D platformers: sprites, frame animation, platformer movement, double jump, camera following, collisions, parallax and UI. FPS and exploration games: first-person controls, pointer lock, raycasts, scripted interactions, animated models, lighting, fog and spatial sound. Arcade racing: vehicle control, chase cameras, checkpoints and lap timing. Physics puzzles: Rapier 3D rigid bodies, colliders, joints, sensors and raycasts, alongside built-in 2D physics. Action and RPG prototypes: baked grid navigation, animation states, combat scripts, effects, loot and menus. Card, board and casual games: sprites, text, interactive UI, input and JavaScript rules. For world building, NIB has terrain sculpting, surface painting, foliage scattering, PBR materials and post-processing. Rendering supports WebGL2 and WebGPU; availability depends on the browser and GPU. Larger systems such as quests, inventory and progression are authored in your game's scripts. The presets give you examples to inspect and modify. Signal Harbor: an illustrated five-level campaign with relays, menus and local save/continue. Character animation and effects The character tools let you adopt an imported skeleton or author a rig, edit bones and weights, preview deformation, create animation clips and connect them through state graphs. Retargeting uses explicit bone mapping; two-bone IK is available for manually configured targets. The character editor, with a visible skeleton and editable rest transforms. The Effect editor combines particle, geometry, trail, light and audio layers into reusable effects. You can preview them, adjust lifetime and curves, then trigger them from scripts or animation events. An effect being edited inside the same workspace as the game scene. Optional local MCP workflow NIB ships with a local MCP server exposing 62 tools . A compatible client can inspect scenes, edit entities and scripts, work with assets, rigs and effects, author terrain or timeline keys, run Play tests, capture screenshots and export games. My preferred loop is simple: inspect the scene, make a bounded change, look at the result and test it. The visual editor remains available throughout. MCP is optional. You can use the editor directly, and any AI client or provider is configured separately. Try the stable release Install Node.js 22.12 or newer . Download NIB-1.0.0.zip , rather than GitHub's automatic “Source code” archive, and extract the entire ZIP into a writable folder. On Windows, run start.bat . On macOS/Linux, run sh start.sh . Keep the local server running and open http://localhost:8670/editor/ in desktop Chrome or Edge. Open File → New Scene (Genres) , choose a preset, confirm Create and press Play. The supplied editor is compiled: no Git checkout, build step or npm installation is required. Save your project and back up the projects folder before upgrading. Current scope: the editor initially targets desktop Chromium. Test exported games on their intended devices. NIB does not supply a built-in multiplayer/cloud backend or mobile/console deployment pipeline. An optional Windows x64 packager can wrap a Single HTML game in Electron. Free to make games; proprietary engine NIB is free for personal, educational and commercial games, with no mandatory subscription or royalties . Your original game code and assets remain yours. The engine/editor is proprietary. The NIB license permits distributing the runtime as part of your games, with the required notices; redistributing or rebranding the standalone engine/editor requires permission.
