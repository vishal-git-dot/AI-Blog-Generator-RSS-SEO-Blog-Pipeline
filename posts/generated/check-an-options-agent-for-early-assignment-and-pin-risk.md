# Check an options agent for early assignment and pin risk

## Overview

If your agent sells covered calls and put spreads, the order check at entry is the easy part. The two problems I care about show up later, while the position sits there: early assignment before an ex-dividend date, and pin risk on expiration day. Both are about the calendar. A covered call that looked fine when it was sold can get assigned the night before the stock goes ex-dividend. A short put that closes a few cents from its strike on Friday can turn into stock you only find out about on Saturday. Over the weekend I posted a short rundown of these risks . This one has the code and the actual responses. I run every open options position through options_risk_check each morning, and again on expiration day. The spread caps the loss at $1,155 only if both legs behave. If SPY closes at $579.90, the 575 long expires worthless and the 580 short can be assigned. That's 300 shares of SPY, about $174,000, in a $25,000 account over the weekend. An agent that only looks at max loss isnt going to see it coming.
