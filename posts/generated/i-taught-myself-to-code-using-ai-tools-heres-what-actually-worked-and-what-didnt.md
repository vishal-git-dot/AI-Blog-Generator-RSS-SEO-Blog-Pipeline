# I Taught Myself to Code Using AI Tools — Here's What Actually Worked (and What Didn't)

## Overview

_A year ago, I only knew Python and C. No CS degree, no bootcamp, just a laptop and a stubborn idea that I wanted to build real things. Today I've shipped a government-scheme-finder assistant, a voice-enabled AI assistant, a chatbot powered by Groq, and a 3D animated portfolio site — almost all of it with AI tools sitting right next to me as a pair programmer. Here's the honest version of what that journey looked like. The myth: "AI writes the code for you" It doesn't. What AI actually does is compress the time between not knowing and knowing. I'd ask it to explain a concept, break a bug, or scaffold a feature — but I still had to read every line, understand why it worked, and fix what it got wrong. The skill I ended up building wasn't "prompting." It was debugging faster because I had a tireless rubber duck that could also write code. What actually moved the needle Building real projects, not tutorials. Tutorials teach you syntax. Projects teach you how things break. Using AI as a reviewer, not just a generator. Asking "what's wrong with this" taught me more than asking "write this for me." Picking one tool and going deep instead of jumping between five AI coding assistants every week. Shipping in public — even small, unpolished projects — because feedback loops beat perfectionism. What I'd tell someone starting today You don't need to know every language. You don't need a CS degree. You need to build something — even something small and ugly — and let AI help you understand why it works, not just that it works. The gap between "I know Python" and "I shipped a product" closes a lot faster than people think, if you're willing to actually read the code AI gives you instead of copy-pasti_ng blind.__
