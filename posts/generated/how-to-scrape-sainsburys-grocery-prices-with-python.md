Sainsbury's is a UK supermarket where shoppers buy groceries online. Troubleshooting common issues The run fails with "0 rows for queries...". The Actor raises a runtime error when zero rows are pushed to the dataset. This occurs if your search terms yielded no products on the site or if strict filters (such as narrow price boundaries or rating thresholds) rejected every candidate item. The run fails with "searchQueries is empty". You must provide at least one grocery search term in searchQueries . If the list is empty or contains only whitespace, the Actor raises this error before requesting any pages. Input rejected with invalid sort option. The sort parameter accepts only RELEVANCE , PRICE_ASC , PRICE_DESC , or RATING . Any other string is refused before the run starts.
