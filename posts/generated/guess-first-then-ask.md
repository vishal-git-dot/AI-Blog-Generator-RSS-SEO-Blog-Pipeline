# Guess first, then ask

## Overview

When you learn, the thing worth protecting is your ability to build a mental model of why the code works. AI only hurts that when it skips you past the model-building. Once you understand something, letting it write the boilerplate is fine. So the question is not how much you use it. It is when. If you try the problem yourself first, or at least predict what the answer will be, the AI becomes a check on your model and an explanation of the why. If you ask first, it becomes a replacement for the model. It was never about using AI less. It is about asking after you have a guess. Kay P.S.
