# I built 50+ free online tools for SEO, text, images and PDF (most run in your browser)

## Overview

I am a web development student, and I built SEOAnalytics Lab, a website with free online tools that I wanted for my own work. It has more than 50 tools in a few groups: Text tools: word counter, case converter, text summarizer Image tools: image compressor, resizer, background remover, upscaler PDF tools: merge PDF, split PDF, JPG to PDF, Word to PDF, PDF to Excel SEO tools: meta tag generator, Open Graph generator, canonical tag and hreflang generators, robots.txt generator Calculators: age, BMI, loan, GPA, compound interest How it works Most tools run entirely in your browser, so your files and text never leave your device. A few tools, such as converting Word files to PDF, need a server, so those files are sent securely, converted and not stored. What I used Next.js and Tailwind CSS for the website Express and MongoDB for accounts and the contact form Gotenberg (LibreOffice) and a small Python service for the document converters Try it https://seoanalyticslab.vercel.app It is free and needs no signup. I would love your feedback, especially on which tool you would like to see next.
