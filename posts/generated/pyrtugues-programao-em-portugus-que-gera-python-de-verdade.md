# Pyrtugues: programação em português que gera Python de verdade

## Overview

Pyrtugues: A Ponte em Português para o Python que Crianças e Iniciantes Precisavam Se você já tentou ensinar programação para uma criança ou para alguém que não fala inglês, sabe qual é o maior obstáculo: a barreira do idioma. Enquanto a lógica de programação é universal, os comandos como if , else , print e def são em inglês. Ferramentas como o Portugol tentam resolver isso, mas trazem uma sintaxe complicada e engessada, que não se conecta com o que o mercado usa. O Pyrtugues nasceu para mudar esse cenário. O que é o Pyrtugues? O Pyrtugues é um projeto educacional de código aberto que funciona como uma ponte para o Python . Ele permite que você escreva código usando palavras em português, mas com a lógica idêntica à do Python. Mais do que isso: o Pyrtugues traduz automaticamente o seu código em português para Python real, que pode ser executado e até mesmo usar a biblioteca Pygame para criar jogos. Como Funciona? A arquitetura do Pyrtugues é simples e poderosa: Você escreve em Pyrtugues: se idade > 10: mostrar("Olá!") O motor de tradução converte para Python: if idade > 10: print("Olá!") O código Python é executado , permitindo que você veja o resultado real. Um Exemplo Prático Veja como é simples a transição: Em Pyrtugues: função saudacao(nome): retornar f"Olá, {nome}!" mostrar(saudacao("Pyrtugues")) Em Python (gerado automaticamente): def saudacao ( nome ): return f " Olá, { nome } ! " print ( saudacao ( " Pyrtugues " )) A lógica é a mesma. A única diferença é a sintaxe, que se torna muito mais amigável para quem está começando. Por que o Pyrtugues é Diferente? Sem Blocos: É programação textual de verdade, com código digitado, como no mundo real. Ponte para o Python: Não te prende em uma linguagem "de brinquedo". Você aprende a lógica e, naturalmente, migra para o Python. Suporte a Pygame: Crie jogos e aplicações gráficas enquanto aprende. Versão Web e Desktop: Use no navegador ou baixe para Windows e Linux. Conclusão O Pyrtugues não veio para substituir o Python, mas para ser a porta de entrada ideal para ele.
