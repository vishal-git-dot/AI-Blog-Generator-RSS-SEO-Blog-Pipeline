# Extract every URL from a sitemap.xml in Python (indexes, .gz, robots.txt) and spot competitors' new pages

## Overview

A site's sitemap is the cheapest full list of its pages you will ever get: the site publishes it for search engines, it usually carries a lastmod date per URL, and reading it takes seconds instead of crawling HTML for hours. That makes it the right starting point for SEO audits, migrations, content inventories, feeding a crawler or RAG pipeline, and keeping an eye on what competitors publish. The catch is that "the sitemap" is rarely one file. Here's what you actually run into, and a small Python script that handles it. What real sitemaps look like Discovery : the reliable place to look is robots.txt , which lists sitemaps on Sitemap: lines (often several). If it has none, try the usual paths: /sitemap.xml , /sitemap_index.xml , /wp-sitemap.xml (WordPress core), /sitemap.xml.gz . Sitemap indexes : big sites publish a <sitemapindex> that points to more sitemaps, and indexes can point to other indexes. Yoast, Rank Math, Shopify and most frameworks split by post type or by 50,000 URLs (the per-file limit in the protocol). Gzip : .xml.gz files are common on news and e-commerce sites. Don't trust the Content-Type header; check for the gzip magic bytes 1f 8b instead. Namespaces : every tag is namespaced ( {http://www.sitemaps.org/schemas/sitemap/0.9}loc ), and image, video, news and xhtml:link hreflang extensions add more. Strip the namespace and match on the local name. No sitemap at all : some well-known sites don't publish one. In my test python.org returned nothing from robots.txt or the common paths, so you need a crawler for those. Loops and duplicates : some indexes list themselves, and the same URL can appear in several sitemaps. Track what you've visited and dedupe. The script Only dependency: pip install requests .
