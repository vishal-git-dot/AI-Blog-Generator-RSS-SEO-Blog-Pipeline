# Show HN: Build with Python – a beginner course where your code draws

## Overview

Hi HN, I built this because I watched my daughter struggle at learning Python. I made something that runs only in the browser with visuals rather than relying on CLI/terminal output. No need to worry about python installation, package versions, venv etc. The lab runs with Pyodide in a web worker, and the program output is a picture by the side of the code block. A user would experiment with the code, and see the immediate changes in the visual output. The course has 13 modules, with the first 6 foundation modules free, module 7-13 with free readings but guide labs for a one-time price of $49. Please give it a try at https://scimigo.com/en/learn/build-with-python Send me feedback on the UX and on the exercise design, especially if you teach kids to program.
