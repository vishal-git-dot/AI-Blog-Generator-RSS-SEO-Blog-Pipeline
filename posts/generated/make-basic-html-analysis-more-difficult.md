# Make Basic HTML Analysis More Difficult

## Overview

This plugin makes saving the page with “Save As” and analyzing it through Developer Tools more difficult. The page is displayed using a Blob URL, so “View Source” is also unavailable. This reduces the number of simple ways to inspect the source. However, some APIs may not work because the page uses a Blob URL. Add the following script: <script src= "https://uni928.github.io/Uni928PublicHTMLs/Plugin/plugin8.js" ></script> Sample: https://uni928.github.io/Uni928PublicHTMLs/index88_sample2.html This is not a complete security measure, but it can make casual analysis more difficult.
