You finish editing a video, hit export, and your Mac tells you there isn’t enough space. Now the job has changed. Before you can publish anything, you have to work out which files you can get rid of. The review screen matters I want the file name and its location to be visible when someone makes a cleanup decision. “This takes up space” is useful information. It doesn’t tell you whether the file matters to you. Aster sends confirmed selections to macOS Trash and never empties it automatically. Moving something to Trash doesn’t immediately recover its storage space; that happens when you empty Trash yourself. Check what is there before taking that final step. The app also discovers installed applications, supported caches and possible leftovers. “Possible” matters here: a related file may still be needed, and some applications require their own uninstallers. Aster does not promise to remove every trace of every app. What you get for free Aster 0.4.1 includes storage scanning, the visual map, large-file search, full paths, Finder actions, supported app and cache discovery, and reviewed cleanup. There is no account to create, license key to enter or checkout to complete. It works on Intel and Apple Silicon Macs running macOS 14 or later. A few questions worth answering Will Aster fix a slow Mac? Aster helps you understand storage and choose files to remove. It does not promise a speed boost, repair hardware or replace a backup. The useful result is knowing what is taking up space and making an informed cleanup decision. Can it delete all of System Data? No. Apple uses System Data as a broad category, not a list of files that are all safe to delete. Aster can help you inspect supported files and cache locations, but it does not offer a blanket “delete System Data” button. Is there a paid unlock? All implemented features in the current release are free. The optional “Buy me a pizza” link supports development; it doesn’t unlock anything.
