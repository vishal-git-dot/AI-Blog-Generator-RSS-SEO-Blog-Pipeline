# Rabarber v6.1: Reliability Update for the Rails Authorization Gem

## Overview

Rabarber , a role-based authorization gem for Rails, releases v6.1.0. This release is mostly about reliability. With the help of AI, a lot of work went into the internals, and many edge cases around transactions, caching, concurrent role changes and generated migrations were found and fixed. Updating is recommended for everyone. This version also adds a way to create and delete several roles at once, and support for binary UUID primary keys in MySQL. A few things are deprecated in this release. They still work for now, but will be removed in the next major version, planned for next year. Details on these and all other changes are in the changelog . Check out the gem here . Happy coding!
