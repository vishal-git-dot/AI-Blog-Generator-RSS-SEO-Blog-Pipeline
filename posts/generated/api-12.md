# 무료 지도 및 지오코딩 API 상위 12개

## Overview

지금 12개 공급자에서 무료 지도 API를 받을 수 있지만, “무료”의 의미는 매우 다릅니다. Geoapify는 카드 없이 하루 3,000건의 요청을 제공하고 상업적 사용을 허용합니다. TomTom은 카드 없이 월 20,000건의 지오코딩을 제공합니다. Google Maps는 SKU당 월 10,000건의 호출을 제공하지만 결제 계정이 필요합니다. Nominatim과 미국 Census Geocoder는 아예 키가 필요 없습니다. 지금 Apidog 사용해 보기 무료 지도 API 한눈에 비교 무료 지도 API는 공개된 할당량 안에서 $0 비용으로 호출할 수 있는 지도, 타일 또는 지오코딩 서비스입니다. 할당량은 보통 요청, 지도 로드 또는 크레딧 단위로 계산되며 매일 또는 매달 초기화됩니다. 대부분 공급자는 한도를 초과하면 서비스를 중단하거나 과금을 시작합니다. 공급자 무료 할당량(2026-10-22 확인) 카드 필요 무료 등급 상업적 사용 Google Maps Platform SKU당 월 10,000건 호출 예, 결제 계정 예 Mapbox 월 50,000회 웹 지도 로드 + 100,000건 임시 지오코딩 아니요(추가 전까지 낮은 데모 한도) 예 HERE Base 플랜 월 30,000건 지오코딩 + 30,000개 타일 예, 결제 수단 예 TomTom 월 20,000건 지오코딩 + 200,000개 타일 아니요 예 Esri ArcGIS Location Platform 20,000건 지오코딩 + 2,000,000개 베이스맵 타일 무료 등급을 초과할 때만 예 Azure Maps 월 5,000건 검색 + 5,000건 지도 타일 트랜잭션 예, 신원 확인용 예 Geoapify 하루 3,000크레딧 아니요 예, 출처 표시 조건 LocationIQ 하루 5,000건 요청, 초당 2건 명시되지 않음 제한적, 백링크 필요 Geocodio 하루 2,500건 조회 아니요 명시되지 않음 MapTiler Cloud 월 5,000회 지도 세션 + 100,000건 API 요청 아니요 아니요, 비상업용 OSM Nominatim 초당 1건 요청, 키 불필요 아니요 가벼운 사용만 미국 Census Geocoder 명시된 할당량 없음, 배치 파일당 10,000개 주소 아니요 예(공공 서비스) 다른 카테고리는 무료 API 가이드 를 참고하세요. 신용카드가 필요 없는 무료 지도 API 이 다섯 곳은 결제 정보를 입력하지 않고 가입하고 프로토타입을 출시할 수 있습니다. 1. Geoapify Geoapify 요금 페이지 는 무료 플랜에서 하루 3,000크레딧을 제공하며, 단순 지오코딩, 장소 또는 경로 탐색 호출은 1크레딧이 듭니다. 속도 제한은 초당 5요청입니다. 페이지에는 “신용카드 불필요”라고 나와 있으며, FAQ에서는 “Powered by Geoapify”와 데이터 출처 표시를 함께 보여주면 운영 환경과 상업적 사용을 허용합니다. 추천 용도: 하나의 키로 지오코딩, 경로 탐색, 타일이 필요한 소규모 상업용 앱. 2. TomTom TomTom 개발자 요금 은 이제 무료 사용량을 일 단위가 아니라 월 단위로 계산합니다. 매달 20,000건의 지오코딩, 20,000건의 역지오코딩, 200,000건의 지도 타일 요청이 제공됩니다. 페이지에는 “신용카드가 필요 없다”고 명시되어 있습니다. 추천 용도: 결제 계정 없이 더 많은 월간 지오코딩 처리량이 필요한 경우. 3. Mapbox Mapbox 요금 에는 월 50,000회 웹 지도 로드(GL JS)와 100,000건 임시 지오코딩 요청이 포함됩니다. 카드 없이 가입할 수 있지만, 카드를 추가하기 전까지는 한도가 낮은 “데모 액세스”(월 5,000회 지도 로드, 10,000건 임시 지오코딩) 상태로 유지됩니다. 결과를 저장하는 영구 지오코딩은 무료 등급이 없습니다. 지오코딩 기본값은 분당 1,000요청입니다. 추천 용도: 웹 또는 모바일 앱에서 세련된 벡터 지도를 쓰는 경우. 4. Geocodio Geocodio 는 종량제 플랜에서 하루 처음 2,500건 조회를 무료로 제공하며, 남은 양은 이월되지 않습니다. 무료 등급을 초과하기 전까지는 카드가 필요 없습니다. 이 플랜의 커버리지는 미국, 캐나다, 멕시코뿐입니다. 추천 용도: 북미 주소 지오코딩과 스프레드시트 정리. 5. MapTiler Cloud MapTiler 무료 플랜 은 카드 없이 월 5,000회 지도 세션, 1,000회 검색 세션, 100,000건 API 요청을 제공합니다. 테스트, 프로토타입, 개인 또는 비상업적 용도로 표기되어 있으며, 지도에 MapTiler 로고를 유지해야 합니다. 추천 용도: 커스텀 지도 스타일을 쓰는 사이드 프로젝트와 프로토타입. 결제 계정이 필요한 무료 등급 다음 네 곳은 할당량 안에서는 무료지만, 먼저 카드 또는 결제 수단을 등록해야 합니다. 첫날부터 예산 알림을 설정하세요. 6. Google Maps Platform Google 요금 페이지 는 Geocoding과 Dynamic Maps를 포함한 각 Essentials SKU에 역법 기준 매달 10,000건의 무료 과금 이벤트를 제공합니다. Maps Embed API는 무제한입니다. 무료 사용을 위해서라도 결제가 활성화된 Cloud 프로젝트가 필요합니다. 지오코딩 결과는 캐싱 제한을 받으며(장소 ID는 저장 가능), 지도에 표시하는 결과는 Google 지도 위에 있어야 합니다. 추천 용도: Google의 장소 데이터와 익숙한 지도 UI가 필요한 앱. Google Maps API 연동 가이드 에서 키 설정 과정을 다룹니다. 7. HERE Base 플랜 HERE 요금 페이지 는 지오코딩, 역지오코딩, 자동완성, 벡터 타일, 래스터 타일 각각에 월 30,000건의 무료 트랜잭션과 “일일 트랜잭션 한도 없음”을 명시합니다. HERE의 2025년 4월 릴리스 노트에는 온보딩 중 결제 수단이 필요하다고 나와 있습니다. 추천 용도: HERE 경로 탐색으로 확장할 물류 및 차량 관제 프로토타입. 8. Esri ArcGIS Location Platform ArcGIS Location Platform 요금 에는 20,000건 지오코딩(비저장), 2,000,000개 베이스맵 타일, 1,000회 베이스맵 세션, 20,000건 경로가 포함됩니다. 결제 도움말에서는 무료 등급을 초과해 종량제를 켤 때만 결제 수단을 추가한다고 설명합니다. 저장 지오코딩에는 무료 등급이 없습니다. 페이지는 비용을 월 단위로 제시하지만 초기화 주기는 명확히 설명하지 않습니다. 추천 용도: GIS 비중이 높은 앱과 이미 ArcGIS 도구를 쓰는 팀. 9. Azure Maps Azure Maps Gen2 요금 에는 월 5,000건 무료 검색 트랜잭션, 5,000건 기본 지도 타일 트랜잭션, 5,000건 위치 확인, 1,000건 경로 트랜잭션이 포함됩니다. Azure 무료 계정 FAQ에서는 신원 확인을 위해 신용카드 또는 체크카드가 필요하다고 안내합니다. 추천 용도: 이미 Azure를 사용하며 같은 청구서에서 지오코딩을 원하는 팀. 키가 없거나 제한적 조건의 무료 지오코딩 API 10. LocationIQ LocationIQ 무료 플랜 은 초당 2요청, 분당 60요청으로 하루 5,000건 요청을 허용합니다. 상업적 사용은 “제한적”이며, 눈에 잘 띄는 "Search by LocationIQ.com " 링크를 추가해야 합니다. 응답은 최대 48시간까지 캐시할 수 있습니다. 추천 용도: 실제 API 키와 상업용 사이트 지원을 갖춘 OpenStreetMap 기반 지오코딩. 11. OpenStreetMap Nominatim 공개 Nominatim 서버는 키와 계정이 필요 없습니다. Nominatim 사용 정책 은 앱 전체에 초당 1요청 한도를 두고, 앱 이름을 나타내는 User-Agent 또는 Referer를 요구하며, 자동완성과 그리드 쿼리를 금지하고 대량 지오코딩은 권장하지 않습니다. ODbL 라이선스에 따라 OpenStreetMap 출처를 표시해야 합니다. 오늘 실행한 테스트 호출은 브란덴부르크 문에 대해 52.5162699, 13.3777034를 반환했습니다. curl -s -A "my-app/1.0 (you@example.com)" \ "https://nominatim.openstreetmap.org/search?q=Brandenburg+Gate&format=json&limit=1" OpenStreetMap 표준 타일은 별도의 타일 사용 정책 을 따릅니다. 즉, 보이는 출처 표시, 7일 캐싱, 대량 다운로드 금지가 요구됩니다. 추천 용도: 트래픽이 적은 도구와 데모. 12. 미국 Census Bureau Geocoder Census Geocoder 는 미국 주소를 좌표와 인구조사 지리에 매칭합니다. 당사의 라이브 호출은 키 없이 백악관을 경도 -77.0352, 위도 38.8987로 매칭했습니다. 배치 파일은 최대 10,000개 주소를 처리합니다. 문서에 속도 제한이 명시되어 있지 않으므로 직접 조절하세요. curl -s "https://geocoding.geo.census.gov/geocoder/locations/onelineaddress?address=1600+Pennsylvania+Ave+NW,+Washington,+DC+20500&benchmark=Public_AR_Current&format=json" 추천 용도: 미국 전용 주소 데이터, 연구, 공공 프로젝트. 두 가지 옵션이 더 있지만 조건이 까다롭습니다. OpenCage 무료 등급은 초당 1건, 하루 2,500건 요청이며 테스트 전용으로 표기됩니다. Stadia Maps는 월 200,000크레딧을 주지만 상업적 사용을 허용하지 않습니다. 어떤 무료 지오코딩 API를 골라야 할까요? 표에서 가장 큰 숫자가 아니라 제약 조건에 맞춰 공급자를 선택하세요. 카드 없는 상업용 앱: Geoapify(하루 3,000건) 또는 TomTom(월 20,000건 지오코딩). 키 완전 불필요: 전역 조회에는 Nominatim, 미국 주소에는 Census Geocoder. 미국 주소 대량 정리: Geocodio(하루 2,500건) 또는 Census 배치 파일. 가장 보기 좋은 웹 지도: 상업용 여부에 따라 Mapbox 또는 MapTiler. 이미 클라우드 요금을 내는 경우: Google Cloud에는 Google Maps, Azure에는 Azure Maps. 앱에 예보도 필요하다면 날씨 API 총정리 가 어느 서비스와도 잘 어울립니다. 할당량보다 중요한 제한 무료 등급은 보통 처리량보다 조건에서 먼저 실패합니다. 저장: Mapbox 임시 지오코딩, Esri 비저장 지오코딩, Stadia 결과는 장기 보관할 수 없습니다. 저장하려면 유료 “영구” SKU가 필요합니다. 출처 표시: Geoapify, LocationIQ, MapTiler, OpenStreetMap은 모두 보이는 크레딧 표시를 요구합니다. 상업적 사용: MapTiler, Stadia Maps, OpenCage 무료 플랜은 수익을 내는 운영 앱에 적합하지 않습니다. 한도 도달 시 동작: MapTiler는 서비스를 일시 중지하고, Mapbox 데모 액세스는 카드를 추가할 때까지 모든 API를 차단하며, Google 또는 Azure는 과금을 시작합니다. 코딩 에이전트에게 Apidog CLI 테스트 맡기기 재시도 루프는 몇 분 만에 하루치 무료 할당량을 태울 수 있습니다. 코딩 에이전트에게 지오코딩 테스트를 한 번 작성하게 하고 변경할 때마다 실행하게 하려면 Apidog CLI 를 사용하세요. npm install -g apidog-cli@latest apidog login --with-token <YOUR_TOKEN> npx -y skills add https://apidog.com # pick your agent when prompted 그다음 Claude Code, Codex 또는 Cursor에 이 프롬프트를 주세요. Apidog 무료 플랜은 최대 4명까지 지원합니다. FAQ 완전히 무료인 지도 API가 있나요? 네. Nominatim, OpenStreetMap 표준 타일, 미국 Census Geocoder는 키가 필요 없습니다. Nominatim의 초당 1요청 같은 공정 사용 규칙 때문에 트래픽이 적은 앱에 적합합니다. Google Maps API는 무료인가요? 부분적으로 무료입니다. Geocoding과 Dynamic Maps를 포함한 각 Essentials SKU는 월 10,000건까지 무료이며, Maps Embed API는 무제한입니다. 그래도 카드가 등록된 결제 계정이 필요합니다. 카드 없이 상업적 사용을 허용하는 무료 지오코딩 API는 무엇인가요? Geoapify는 출처 표시 조건으로 무료 플랜에서 상업적 사용을 허용하고, TomTom의 무료 월간 요청에는 카드가 필요 없습니다. LocationIQ는 백링크 조건으로 제한적 상업적 사용을 허용합니다. 무료 지오코딩 API 결과를 저장할 수 있나요? 대체로 불가능합니다.
