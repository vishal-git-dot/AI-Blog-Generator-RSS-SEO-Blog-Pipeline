# How to Export Public Telegram Channel Posts to CSV (Text, Views, Dates, Links) Without an Account or API Key

## Overview

A lot of public information appears on Telegram first. Exchanges post listings and delistings there, projects announce releases, and news channels push stories before the website updates. If you research a market or monitor a competitor, you will eventually want those posts in a table: one row per post, with the text, date, view count and links. The official routes are awkward. The Bot API only sees channels where your bot is an admin. The full MTProto API (Telethon, Pyrogram) works, but needs a Telegram account with a phone number, an api_id from my.telegram.org and a session file to keep safe. That is a lot of setup for posts anyone can already read at t.me/s/<channel> in a browser. This tutorial uses an Apify Actor that reads that public web preview and exports the posts as JSON, CSV or Excel. Disclosure: I built and maintain this Actor. It is a paid tool ($1.00 per 1,000 results). The limitations section at the end is as important as the rest. What you can do with the data Monitor announcement channels. Pull 30 days of an exchange's channel and tag each post: delisting, new listing, maintenance, promotion. Compare channels. Views per post, posting frequency and hours, and which sites they link to. Build a research dataset. Original-language text with dates and engagement, ready for topic or sentiment analysis. Limitations These mostly come from what Telegram shows on its public web preview: Public channels only. Private channels, invite links ( t.me/+... ), groups, bots and user accounts can't be read. They are skipped with a warning in the log. Some public channels have no web preview. Owners can turn it off, Telegram hides some restricted channels, and a channel blocked in the country of Apify's servers looks like it doesn't exist (a proxy can help). No comments. Comments under posts aren't part of the web preview. Views and reactions are rounded by Telegram above 1,000 ("20.7K" becomes 20700), so small differences between posts don't mean much. Views keep growing after a post goes out. In my sample, Binance posts from four days earlier had more than twice the views of the newest ones. Compare posts of similar age, or re-run later. Some post types show no content on the web. Live streams, giveaways and paid media come back with empty text and a mediaNote . Media links expire. The Actor saves links to photos and videos, not the files. Download them soon if you need them. Search returns at most about 22 posts per channel and keyword. For more, scrape the channel's posts and filter them yourself, as in the example above. Old posts take time. The Actor reads newest to oldest at roughly 1,000 posts a minute. Personal data. Author signatures and forwarded-from names can identify people. If you store them, make sure you have a legitimate reason under GDPR or similar laws. If you track many channels, run channelInfo mode daily to build a subscriber history. The store page has more input examples.
