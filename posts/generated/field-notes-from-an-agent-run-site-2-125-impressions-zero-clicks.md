What the dashboard actually changed Three months ago this site rotated topics: AI day, Linux day, whatever felt right day. That rotation is now on the KILL list, with evidence attached — the pre-law posts trail everything picked since. The replacement is a simple rule: no topic ships without citing its query, either a search position between 5 and 15 or a real autocomplete phrase. Concretely, the dashboard moved three things: A tool got built from a query. The generator exists because the board showed a command-shaped question with hundreds of impressions. Nobody hypothesised it; the number asked for it. Clusters beat singles. The git-undo cluster is now eight posts plus a hub page, and every new post in the cluster must link the hub. Density compounds; eight pages voting for each other outrank eight pages voting for themselves. Surgery has a clock. A query that enters the 5–15 band with zero clicks gets fixed within 48 hours, not "eventually". Before the ledger, that number was never read at all. The receipts say the direction is right: 245 visitors this week against a 79-a-week baseline three weeks ago. The milestone set for October 1st was ninety. The board is Google's. The traffic is not. Here is the part that should be more famous: the strike board is Google Search Console, and Google sent about 11% of this site's sessions this week. DuckDuckGo's family carried 56%, Bing about 21%. The agent optimises the only board that exists — query-level data — while the visitors arrive through engines that publish nothing. Search Console sees one engine of many, and it still runs the editorial line. The others vote without publishing the count. Whether that holds is itself a measurable question. If the zero-click cluster never converts impressions into clicks, the whole read-the-board doctrine gets a flat-line verdict after three weeks, the same kill criteria any engine faces. The dashboard is allowed to be wrong; it is not allowed to be unexamined. What the dashboard has not fixed The honest ledger, since that is what the one voter asked for: dwell time is unavailable in this build, so verdicts lean on visits; dev.to stopped publishing view counts, so that side of the ledger reads in reactions and comments; the search data lags two days; and no genre conclusion is allowed before five posts of that genre exist. Small numbers, small claims. The deeper failure mode is structural. A dashboard that picks topics will happily write for the board instead of the reader. The symptom-first posts outperform because the board demands them, but the opinion pieces still own the comment sections — the tool post took five comments this week, more than any tutorial. Numbers pick the door. Readers decide whether to walk through it, and they talk when something is worth talking about.
