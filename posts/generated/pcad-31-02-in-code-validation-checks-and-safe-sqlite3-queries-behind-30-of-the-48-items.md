Objective 2.4.1 lists the clauses the exam expects you to combine: SELECT, FROM, JOIN, WHERE, GROUP BY, HAVING, ORDER BY and LIMIT. The query below uses all of them, with a LEFT JOIN so that an order from a country missing in the lookup table is kept and labelled rather than dropped. con . executescript ( """ CREATE TABLE countries (code TEXT PRIMARY KEY, region TEXT NOT NULL); INSERT INTO countries VALUES ( ' BR ' , ' Americas ' ), ( ' NG ' , ' Africa ' ), ( ' IN ' , ' Asia ' ); """ ) QUERY = """ SELECT COALESCE(c.region, ' Unmapped ' ) AS region, COUNT(*) AS orders, ROUND(SUM(o.amount), 2) AS revenue, MIN(o.order_date) AS first_order FROM orders AS o LEFT JOIN countries AS c ON c.code = o.country WHERE o.paid = :paid GROUP BY region HAVING COUNT(*) >= :min_orders ORDER BY revenue DESC LIMIT 5 """ summary = pd . read_sql_query ( QUERY , con , params = { " paid " : 1 , " min_orders " : 1 }) print ( summary ) print ( summary . dtypes ) region orders revenue first_order 0 Africa 1 310.00 2026-09-04 1 Americas 2 192.75 2026-09-01 2 Unmapped 1 89.90 2026-09-05 region str orders int64 revenue float64 first_order str dtype: object The params argument of pandas.read_sql_query passes values to the driver, so the placeholder rule still holds.
