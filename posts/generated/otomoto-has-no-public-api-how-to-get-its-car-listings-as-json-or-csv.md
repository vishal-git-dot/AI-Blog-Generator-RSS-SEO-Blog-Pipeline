# Otomoto has no public API: how to get its car listings as JSON or CSV

## Overview

Otomoto.pl is Poland's biggest car marketplace, with private sellers and most of the country's dealers. If you want its listings in code, to price a car, track depreciation or watch a rival dealer, you find out quickly that Otomoto has no public API for searching listings. This post shows two ways to get them anyway: without code, and from Python. All the output below comes from real runs on 15 November 2026. Disclosure: we built and sell the tool used here, the Otomoto.pl Scraper on Apify, and an AI agent wrote this post. The numbers are from real runs, not made up. Without code: paste a search URL Search on otomoto.pl as usual: make, model, price, city. Copy the address from your browser. Open the Otomoto.pl Scraper , paste the address into Start URLs and press Start. Download the results as CSV, Excel or JSON. Cars from 2017 to 2019 sit between 44,000 and 50,000 PLN, and 2020 jumps to 65,500. The fourth-generation Octavia went on sale in 2020, and the 2020 cars have about 50,000 km less on the clock. Young cars, high mileage. 61 of the 106 cars from 2023 have already passed 100,000 km, and 370 of the 500 listings come from businesses rather than private sellers. If you want a low-mileage car, filter on mileageMax instead of the year. Most prices look fair by Otomoto's measure. Of the 392 cars with a badge, 81% were within market, 13% below and 6% above. Some of the cheap outliers are damaged cars. A 2023 Octavia at 14,900 PLN turned out to be marked "Uszkodzony" (damaged) on its page. Search mode doesn't return that flag, but detail mode adds a damaged field (true or false), so use detail mode if you want to drop those cars before taking medians. These are the first 500 Octavias in Otomoto's default order, not the whole market. Raise maxItems (up to 5,000) for a fuller picture. Watch prices instead of downloading them Monitor mode returns only what changed since the last run: new cars, price changes and removed listings. To follow one dealer, save this input as a task and give it a daily schedule: { "startUrls" : [ { "url" : "https://AUTO21KRKOCMYRZOWSKA.otomoto.pl/inventory" } ] , "mode" : "monitor" , "maxItems" : 200 } The first run records everything the dealer has today. From then on, each row carries changeType ( new , changed or removed ), the previous price, the full price history and the days on market. Apify can send the rows to Slack, email or a webhook after each run. You can point it at a search URL in the same way, for example every Octavia RS under 80,000 PLN, and get a morning list of new cars and price cuts. What it costs $0.75 per 1,000 cars, so the 500-car run above cost about $0.38. Apify's free plan comes with $5 of credit a month, which covers about 6,600 cars. In monitor mode you pay only for new and changed cars, so a day with no changes costs nothing. Limits worth knowing You don't get phone numbers or email addresses, and the tool doesn't collect private sellers' names. Dealer names are included. Many sellers hide the VIN. None of the 20 newest Octavias in our test run showed one. Otomoto copies some listings from OLX. Those come with fewer fields, often without the version or the price badge. The tool reads public pages without logging in. Check Otomoto's terms and your local law for what you do with the data.
