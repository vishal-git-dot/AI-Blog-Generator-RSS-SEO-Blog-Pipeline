# x402 TypeScript Tutorial: Let Your AI Agent Pay Per Call for Web Search (Node.js)

## Overview

If you build agents in TypeScript, you've probably hit the same wall every time you add a web tool: sign up, verify an email, copy an API key into .env , pick a plan. Then do it again for the next tool. x402 removes that step. The server answers an unpaid request with HTTP 402 Payment Required and a machine-readable price. Your client signs a small USDC payment, retries, and gets the answer. There's no account, no key and no monthly plan, so an agent can pay for exactly the calls it makes. This guide builds that in Node.js with TypeScript, step by step: Read a live 402 price for free, with plain fetch . Pay per call with @x402/fetch . Wrap search and page reads as agent tools with a hard budget. Run them in a tool-calling loop with the OpenAI Node SDK. The API is AgentSearch's direct x402 API at api.agentsearchhq.com , on Base mainnet. The same code works for any x402 v2 seller. What it costs Live prices from GET https://api.agentsearchhq.com/x402/v1/pricing : Endpoint What it does Price per call POST /x402/v1/search Live web search, ranked results as JSON $0.003 POST /x402/v1/extract Any public URL to clean markdown $0.002 POST /x402/v1/search_and_read Search plus the top pages as markdown, one call $0.005 POST /x402/v1/render JavaScript-heavy pages in headless Chromium see Render Payments are USDC on Base, x402 v2 exact scheme, settled through the Coinbase CDP facilitator. Failed and empty calls are never settled: payment is verified first and only settled after a usable answer. A typical "search once, read two pages" question costs $0.003 + $0.002 + $0.002 = $0.007 . An x402 exact payment is a single transfer of the listed amount with a short validity window. FAQ Do I need an AgentSearch account or API key? No. The 402 response is the price list, and the signed payment is the authorization. Which network and token? USDC on Base mainnet ( eip155:8453 ), x402 v2 exact scheme, through the Coinbase CDP facilitator. No ETH needed for gas. Does this work in the browser or on edge runtimes? The @x402/fetch wrapper only needs a fetch implementation and a signer, so it runs anywhere fetch does. Don't ship a private key to a browser, though. For agents, keep the wallet on a server, a worker or a CLI process you control. Can I use axios instead of fetch? Yes. @x402/axios exposes wrapAxiosWithPaymentFromConfig with the same schemes config. There's a copy-paste example in the direct x402 API docs . What happens if a call fails? Nothing is settled. Payment is verified first and only settled after a successful, non-empty answer.
